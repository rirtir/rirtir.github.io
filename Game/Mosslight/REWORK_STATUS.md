# 2026-10-08 改修の記録

主人公は未承認の仮画像。作者が後日制作する正面絵を新基準に差し替える。今回の技術確認は造形の承認や参照作品との品質同等性を意味しない。人物の追加作画は行っていない。

## 反映した変更

- 色・法線・高さを分け、太陽の向き、夕暮れ、暗い夜、局所光を計算する。自然物は色と法線Xを同時に反転する。旧資産も残っており、全資産の焼き込み光を除去したわけではない。
- 草と土を世界座標の有機的なマスクで合成し、葉・小石・草を散らす。耕地は16接続パターンで外周だけを描く。
- 木の幹を直立させ、樹冠を大きな葉の塊として描く。小物・一部家具・岩・植物・床・壁・屋根の材質も更新する。
- 木や岩の当たり判定、構造物の操作位置、描画順、影の足元を揃える。
- 通常アセット読み込みで歩幅・位相が失われる不具合を修正。移動距離に従って歩く。人物の輪郭・反転・縮小は配列型とオブジェクト型の足情報を扱う。
- 地面へ投影済みの局所影と疎なheight rayを二重に適用していたため、支柱の影が離れた四角に繰り返されていた。地面では投影影を使い、高い受光面・未投影光ではrayを保つ。
- 入室時に屋根を完全に外し、半透明の屋根枠を残さない。出入りのフェードを保つ。
- 主人公アトラスの未使用のトップ補助情報を整理し、保存ソースから配布物を再出力できるようにした。

## 独立レビューと確認

Claude Opusが昼・夜・屋内の3画面を評価し、上記の影・屋根の問題と人物の照明確認を指摘した。Claude Sonnetが屋根と人物メタデータ変換を修正し、Codexが統合・実行を確認した。別のレビュー担当がゲーム操作、アセット契約、修正後の画面を独立に確認した。

主人公を同じ位置・向きに固定し、23時に光源0→制作した松明1へ切り替えた。設置後は顔・服・地面が暖色で照らされる。法線・高さを未提供にしたfallbackでも照明は当たる。地上の無料周辺光は追加しない。

通常manifest・実WASDで4方向の歩行を撮影し、歩幅6pxの読み込みを確認した。実入力で木・岩へ接近すると足元の拡張楕円の境界で止まった。採集、松明の実UI制作・設置、家の入退室、夜と地下のGL/2D切替、縦画面操作を確認した。確認画像と個人の利用量は公開対象外のローカル記録に保存する。

全量rebuildでは40シートを再出力し、正本と配布物のバイト一致を確認した。ゲームルール・地面・照明・足元の回帰、操作・保存・場面・アセット検査は [tests/TEST_PLAN.md](tests/TEST_PLAN.md) を参照。
