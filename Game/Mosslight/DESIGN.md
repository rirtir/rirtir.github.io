# 苔灯の境 / MOSSLIGHT 設計書

## 0. 概要と制約

森の野営地から始め、採集・建築・栽培・料理で暮らしを整えます。苔の洞窟と古い遺跡を探索し、消えた3つの灯を復元するのが目的です。主進行は45〜90分で、クリア後は生活と建築を続けられます。

- 静的GitHub Pagesで動き、ビルドは不要です。ES modules、Canvas2D、外部CDNなしで実装します。
- 既存のサバイバルクラフト作品のコード・画像は参照しません。参考作品の画面やキャラクターも模倣しません。
- 固定シード `0x4D4F5353`（"MOSS"）を使います。地上は128×128、地下は96×96、タイルは32px です。

## 1. 体験の柱と主進行

### 体験の柱
1. **歩くだけで心地よい世界**: 草花の揺れ、葉の透過、暖色の灯、地下の発光、足音の材質差で世界を感じさせます。HUDは最小限にします。
2. **拠点と探索の循環**: 地上の資源と料理が洞窟攻略を支えます。洞窟の鉱石と灯は拠点を広げ、明るくします。
3. **迷わない進行**: 日誌に常に「次の一手」を1行で出します。3つの灯は世界の中の「境の塔」の火としても見えます。
4. **失っても詰まない**: 装備は失いません。NPCは不死身です。進行アイテムは必ず到達可能な場所に置き、ボスは何度でも再挑戦できます。

### 主進行（目安時間）

| 段階 | 目標 | 目安 |
|---|---|---|
| 導入 | 枝3・石3・繊維2を集め、石の斧を作る | 0〜4分 |
| 野営 | 木材を集めて作業台、石のツルハシ・鍬を作る。畑に芋を植える | 4〜12分 |
| 住まい | 有効な家を1軒建てると料理番ツグミが来訪する。湖岸の粘土で精錬炉を作る | 12〜22分 |
| 灯1 炉の灯 | 炉の祭壇に銅インゴット4・苔灯油2・森のシチュー1を捧げる（家1軒も必要） | 22〜35分 |
| 灯2 苔の灯 | 洞窟の光苔結晶3個を苔の祭壇に置き、ヌシカズラを鎮める | 30〜55分 |
| 灯3 古灯 | 封印扉の先で灯皿3つに苔灯油を灯し、灰の番人を倒して古の灯芯を古灯台へ運ぶ | 50〜90分 |
| クリア後 | 生活の目標8項目、ボス再戦、自由建築 | 任意 |

- 灯1と灯2はどちらから進めてもかまいません。
- 封印扉は灯1と灯2の両方が復元されると開きます。

## 2. 必須機能と受け入れ条件

| 機能 | 受け入れ条件 |

| 畑 | 規定秒数で成長する。睡眠でスキップした時間も成長に反映される。 |
| 昼夜・満腹 | 1日600秒で巡る。満腹0でもHPは20未満にならない。 |
| 戦闘 | 全攻撃に0.4秒以上の予兆（見た目＋音）がある。回避の無敵時間中は被弾しない。 |
| 死亡 | 装備・鍵アイテム・食料・設置物は保持される。素材は資源袋に入り、マップに表示されて回収できる。 |
| 再生 | 採集物と敵は規定時間・上限に従って戻る。 |
| 到達性 | 生成後の検証で、全進行物が初期地点から到達可能（ログにOK）。 |
| NPC | NPCは死なず、進行条件に含まれない。家が壊れても詰まない。 |
| 保存 | 自動保存、書き出し、読み込みができる。破損データは拒否し、元のデータを上書きしない。失敗は画面に表示する。 |
| 一時停止 | ダイアログ表示中とタブ非表示中はシミュレーションが止まる。 |
| 入力 | キーボード＋マウスだけ、タッチだけのどちらでもクリアできる。 |

## 3. 数値仕様

### 3.1 基本
- **プレイヤー**
  - HP最大100。被弾後0.6秒は無敵、0.4タイル押し戻されます。
  - 移動速度は4.5タイル/秒。道の上では+15%、浅瀬では60%になります。
- **満腹**（最大100）: 7.2秒ごとに−1（720秒で0）。睡眠1回で−15です。

| 満腹 | HP回復 | その他 |
|---|---|---|
| 60以上 | 2秒ごとに+1 | — |
| 30〜59 | 6秒ごとに+1 | — |
| 1〜29 | なし | — |
| 0 | なし | 移動−20%、4秒ごとにHP−1（20で止まる） |

- **昼夜**（600秒周期）

| 時間帯 | 秒 | 地上の環境光 |
|---|---|---|
| 夜明け | 0〜60 | 補間 |
| 昼 | 60〜390 | 1.0 |
| 夕暮れ | 390〜450 | 補間 |
| 夜 | 450〜600 | 0.35 |

  - 夜はプレイヤーの周囲半径2タイルを照らします。地下の環境光は0.12で、プレイヤーの光は半径3タイルです。
- **睡眠**: 有効な家のベッドで、時刻390以降に使えます。翌日の30秒まで進め、スキップした秒数を再生と作物に加算します。
- **死亡**
  - バッグ内の「素材」カテゴリだけを資源袋に入れます。
  - 復活地点は最後に寝たベッド、なければ焚き火です。HP60、満腹は max(現在値, 40) で復活します。
  - 資源袋は同時に1つだけです。回収前に再び死ぬと、旧袋の中身を新袋へ統合します。

| 敵 | 場所・出現上限 | HP/軽減 | 予兆 → 攻撃 | 威力 | 報酬 |
|---|---|---|---|---|---|
| 苔スライム | 地上・常時 6 | 20/0 | 縮んで緑に光る0.5秒 → 3タイル跳躍 | 6 | ゼリー1 |
| 影ギツネ | 地上・夜のみ 4 | 35/0 | 尾が赤く揺れる0.6秒 → 5タイル突進 | 10 | 毛皮1 |

| 岩甲虫 | 苔層・遺跡 4 | 60/3 | 体を沈める0.8秒 → 4タイル突進、後に1.2秒硬直 | 14 | 甲殻1 |

- 出現判定は20秒ごとです。プレイヤーから14〜22タイル離れた画面外で、安全圏＋6タイルの外に出します。
- 索敵半径はスライム5、キツネ8、コウモリ6、甲虫6タイルです。
- 出現地点から14タイル離れると、敵は元の場所へ戻ります。

**ボス1 苔の母樹ヌシカズラ**（苔の祭壇、円形の闘技場半径7）: HP400、軽減0
- 蔓叩き: 1.0秒間、緑の線が光る → 長さ6・幅1の直線に18ダメージ。
- 胞子: 1.2秒間膨らむ → 8方向に3タイル/秒で飛ぶ弾、各8ダメージ。
- HP50%以下: 15秒ごとにスライム2体を召喚（最大4体）。
- 報酬: 苔の灯芯、翠鉄鉱石10。帰還の蔓が開通します（祭壇と地上の炉の祭壇を双方向に移動）。

**ボス2 灰の番人**（遺跡の闘技場）: HP700、軽減4
- 腕振り: 0.7秒間腕を上げる → 前方120°・半径2.5に22ダメージ。
- 灰炎の輪: 1.2秒間、床の輪が光る → 20ダメージ。HP50%以下では2連続になります。
- 突進: 0.9秒間目が赤く光る → 8タイル突進。壁に当たると2秒気絶し、その間は被ダメ1.5倍。
- 報酬: 古の灯芯。

**ボス共通**
- 敗北するとボスのHPは全快します。置いた結晶などの進行状況は保持します。
- 闘技場から10タイル離れて5秒経つと、ボスはリセットされます。
- クリア後は祭壇から再戦できます。報酬は翠鉄鉱石10です。

### 3.7 3つの灯の復元条件
1. **炉の灯**: 野営地の炉の祭壇に銅インゴット4・苔灯油2・森のシチュー1を捧げ、安全圏内に有効な家が1軒以上あること。復元すると安全圏の半径が14から20に広がります。
2. **苔の灯**: 光苔結晶3個を苔の祭壇に置くとボス1が出現します。撃破後に苔の灯芯を祭壇に置くと復元します。
3. **古灯**: 灯1と灯2の復元で封印扉が開きます。遺跡の灯皿3つに苔灯油を1つずつ灯すと、闘技場の扉が開きます。ボス2撃破後、古の灯芯を古灯台に置くとエンディングになります。

各灯の復元で境の塔の火皿が1つ点灯し、全体のBGMが1段明るくなります。

## 4. 操作・インタラクション・戦闘

| 操作 | キーボード/マウス | タッチ |
|---|---|---|
| 移動 | WASD/矢印 | 左下の仮想スティック |
| 行動（採集/攻撃/調べる） | 左クリック・長押しで連続 / E・Space | 対象をタップ / Aボタン |
| 回避 | Shift | 回避ボタン |
| ホットバー | 1〜8、ホイール | スロットをタップ |
| バッグ / 制作 / 建築 / マップ / 日誌 | Tab・I / C / B / M / J | 右上のメニュー |
| 取り壊し / 回転 | X / R | 建築モードの切替ボタン |
| 設定・閉じる | Esc | ✕ボタン |

- **距離**
  - 採集・調べる: 足元から対象の中心まで1.5タイル（48px）。
  - 建築: 6タイル。
  - 設備の利用: 3タイル。
  - キーボードで行動するときは、向いている方向の90°・1.5タイル以内で最も近い対象を選びます。
  - 対象の優先順位は 落下物 > NPC > 設備 > 資源 > 敵 です。
- **自動道具**
  - 木→斧、岩・鉱床・壁・粘土→ツルハシ、耕せる地面→鍬（建築の畑カテゴリまたは種を持っているとき）、敵→剣。所持している中で最上位の段階を使います。
  - 道具はホットバーを占有しません。ホットバーは食べ物と設置物用です。
  - 1回の振りは0.4秒です。素手の採集は0.3秒です。
- **攻撃**
  - 振りの全体時間は0.45秒で、0.10〜0.20秒が攻撃判定です。範囲は前方100°・1.5タイルです。
  - ヒット時にヒットストップ50msを入れます。通常の敵は0.5タイル押し戻し、ボスは押し戻しません。
  - 振り始めから0.25秒以降は回避でキャンセルできます。
- **回避**: 0.25秒で2.5タイル移動します。開始から0.2秒は無敵です。再使用まで0.8秒で、消費はありません。
- **衝突**
  - プレイヤーは足元の円（半径10px）で判定し、壁に沿って滑ります。
  - 木の幹は半径10px、岩は半径14pxです。
  - 敵の当たり判定はスライム10、キツネ12、コウモリ10、甲虫14、ボス36pxです。
  - 深水、壁、柵、閉じた扉は通れません。扉は自動で開閉します。

## 5. 地形生成・保証配置・到達性

**乱数**: mulberry32（シード固定）。value noise の fbm（4オクターブ）を使います。生成バージョン `genVersion=1` をセーブに記録します。

### 地上（128×128）
1. 外周3タイルは通れない崖・密林にします。
2. 主要地点を固定座標に置きます。

## 7. UI構造

- 世界を主役にし、HUDは四隅に小さく置きます。DOMで作り、Canvasの上に重ねます。
- 共通パレット: 苔緑 `#4f7a3a`/`#7fa650`、黄土 `#b88a4a`、深い青緑 `#13302f`/`#1f4a4f`、暖かい金 `#f2b950`/`#ffd98a`、墨 `#1a1a1f`。
- **スタート画面**
  - 項目: 続きから（保存日時・灯の数・プレイ時間）／はじめから（セーブがあれば確認）／読み込み／設定。
  - 導入は3行の文章だけです。
- **最小HUD**
  - 左上: HPと満腹の細いバー。
  - 右上: 時刻の円盤と、目標1行。
  - 下中央: ホットバー8枠。
  - 左下: 通知（最大3件、3秒で消える）。
  - 対象の横: 「E 伐る」などの文脈表示。
  - 操作説明は、初回に移動・採集・制作・建築の4回だけ出します。

- **建築**: タブ（床・道／壁・扉・柵／家具／灯／畑）。半透明の緑・赤プレビュー、X取り壊し、右クリックで解除します。ゲームは止めません。
- **マップ**: 探索済みの範囲だけ表示し、地上と地下を切り替えられます。印は拠点・入口・祭壇・資源袋・発見済みの結晶です。
- **日誌**
  - 現在の目標と、3つの灯の進捗チェック（例: 銅インゴット 2/4）を表示します。
  - クリア後は生活の目標8項目を表示します（家4軒、灯籠8、畑12、料理6種、住人3人、道60マス、翠鉄一式、両ボス再戦）。全達成で「苔灯の噴水」を1つ贈ります。

  - 保存するたびに右下でアイコンが0.8秒点滅します。

- **フォーカス**

  - 入力欄にフォーカスがある間は、ゲームのキーを無効にします。

## 8. セーブ構造と検証

保存キーは `mosslight.save.v1`（直前の正常データは `mosslight.save.backup`）、設定は `mosslight.settings` です。

```json
{ "format":"mosslight-save", "version":1, "genVersion":1, "savedAt":"ISO", "playTime":0,
  "player":{"map":"surface","x":0,"y":0,"hp":100,"satiety":100,
    "tools":{"axe":1,"pick":1,"hoe":0},"equip":{"weapon":"sword_stone","armor":null,"trinket":null},
    "hotbar":[null],"bag":[{"id":"wood","n":4}],"spawn":{"map":"surface","x":0,"y":0},"buffs":[]},
  "world":{"clock":0,"day":1,"structures":[{"id":1,"type":"wall_wood","map":"surface","x":0,"y":0,"rot":0}],
    "containers":{"1":[]},"nodes":{"surface:12,40":{"respawnAt":1234}},"mined":{"underground":"base64"},
    "explored":{"surface":"base64","underground":"base64"},"crops":[],"groundItems":[],"deathBag":null},
  "progress":{"lights":{"forge":false,"moss":false,"ancient":false},"crystalsPlaced":0,
    "bosses":{"vine":false,"ash":false},"braziers":[false,false,false],"npcs":{},"goals":{},"cleared":false} }
```

- **差分保存**: 世界はシードから再生成し、差分（構造物、採掘済みビット、ノードの状態）を当てて復元します。
- **時刻**: 再生や作物の時刻は、単調に増える `world.clock` の秒数で管理します。
- **保存の契機**: 60秒ごと、夜明け、灯の復元、ボス撃破、非表示時、`beforeunload` で保存します。`setItem` の例外は捕まえて表示します。
- **検証**
  - `format` が一致し、`version` が現行以下の整数であること。
  - 必須フィールドの型が正しいこと。
  - 数値は範囲内に丸めます。
  - 未知のアイテムIDは捨て、件数を通知します。
  - 座標がマップ外や壁の中なら、復活地点へ移します。
  - `genVersion` が異なる場合は警告します。
- **マイグレーション**: `MIGRATIONS[v](save)→v+1` を順に適用します。v1は初期版です。
- **読み込み失敗時**: バックアップの読み込みを提案します。どちらも失敗した場合は理由を表示し、何も上書きしません。
- **書き出し**: `mosslight-save-YYYYMMDD-HHMM.json` をBlobでダウンロードします。
- **読み込み**: ファイルを選択し、検証してから上書き確認のうえで読み込みます。

## 10. テスト

### ブラウザテスト
- 起動時にコンソールエラーがない。`validateData()` と到達性レポートがOK。
- 30fpsへの制限と144Hzで、移動距離の差が5%以内。
- 石の斧が5分以内に作れる。木が石の斧3回、銅2回、翠鉄1回で倒れる。
- 硬度2の壁に石のツルハシを使うと、案内が表示される。
- 壁・家具の設置と取り壊しで資源が完全に戻る。家判定と屋根の表示・非表示が切り替わる。
- 苔芋が180秒（灯の近くなら144秒）で熟す。睡眠のスキップが反映される。
- 満腹0でHPが20で止まる。死亡後に資源袋を回収でき、装備は保持される。
- NPCの家を壊しても例外が出ず、進行は可能。
- ダイアログ表示中とタブ非表示中に `clock` が進まない。
- 保存・再読み込みで全進行が一致する。破損JSON、未来のversion、未知IDをそれぞれ正しく処理する。容量超過を模擬すると赤帯が出る。
- キーボードだけ、タッチエミュレーションだけでメニューを一巡できる。
- `?debug=1` の `give/teleport/setTime/setLights` で各灯を単独で確認できる。

### プレイテストの観点
- 初見で次の目標に迷う時間が30秒を超えないか。
- 同じ採集を3分以上繰り返す区間がないか。
- 予兆を見て回避できるか。
- 灯1と灯2を逆の順で進めても破綻しないか。
- 夜や地下でもアイテムと地形が判読できるか。
- 拠点に帰ると安心感があるか。
- 合計の進行時間が45〜90分に収まるか。
