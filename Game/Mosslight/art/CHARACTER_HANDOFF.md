# 主人公の差し替え

2026-10-08: 現行Explorer4の造形はユーザーが拒否した仮画像。技術検査・レビュー合格を美術の承認と扱わない。作者が後日制作する正面立ち絵を新しい基準とする。現在の絵に合わせたNPCの追加作画は見送る。

正面絵は作者の原寸・頭身・パレットを尊重する。現在の48×72/pivot24,58や旧案Cの部品構成は制約ではない。追加の向き、動作、法線、高さ、握り位置は受け取った絵を基準にこちらで用意する。縮小画像の整形や細部の追加によって元の画素構成を変えない。

統合先は `explorer` シートの48フレーム。フレーム名は [ART_CONTRACT.md](../ART_CONTRACT.md) を参照。キャンバス・足元pivotはmanifestとatlas、手・足・歩幅は `explorer-poses.json`、色と形状の正本は `explorer.json` と `normalmaps/explorer-{normal|height}.json`。新しい正面絵から名前付き部品を作り、各動作の部品を組み替える。左右反転時は法線Xと座標も反転する。

`build_explorer4.py` と `build_hero_studies4.py` は仮の案C専用の制作履歴。任意の絵を読み込むツールではなく、新しい絵を差し替えた後に実行すると旧案へ戻る。新しい正本をこれらで再生成しない。通常の `rebuild.py` は保存された正本だけを再出力し、旧案の生成器を実行しない。

ランタンを持たない絵はメタデータの `lantern` をfalseまたは `{visible:false}` にする。地上夜の無料灯は追加せず、制作・配置したたいまつや灯籠を使う。形状の粗さ・起伏・輪郭の読みやすさは昼、低い夕日、近い松明、光源外、歩行・攻撃・回避で実画面を確認する。

再出力後はcheck-onlyに加えて全量rebuildを行い、配布PNG/JSONがバイト一致することを確認する。実ゲームの通常manifestから読み込み、候補を上書きしたプレビューだけで完成と判定しない。
