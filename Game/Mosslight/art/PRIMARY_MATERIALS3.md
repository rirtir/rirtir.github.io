## 形の作り方

- **岩（Stone）**: 不規則な凸多角形。面ごとに傾きが違う屋根形で、画面の前向きの面は急（.42+.85）、後ろ・横は緩く、頂は `top` で平らになる。面の傾きの乱数は光の向きと無関係。1フレームに 3〜5 個の岩が重なり、高さ + 手前補正の大きい方が勝つので、岩どうしの境が「接触線」になる。
- **銅・鉄の鉱脈**: 宿主の岩の中を、値ノイズの等高線（|n−.5| が小さい帯 + 枝）が走る。色は顔料（銅: `#934f3f #b4642e #e0965a` + 緑青の斑、翠鉄: `#21485f #2f6476 #5d9aa0` + 淡い塊）。さらに、ほぼ全面が鉱石の露頭 2 つを置いた。鉱脈の明暗は光ではなく顔料の違い。
- **結晶**: 軸に沿った 2 面の角柱で、先が尖る。芯の帯だけ法線 61（発光の印）にしてある。発光は結晶だけ。
- **低木・実**: 枝（カプセル）ごとに 3 組の対の葉と先端の 1 枚を付けた群。葉は中肋を稜線にした 2 面で、葉ごとに高さの段（0〜4.5）が違うので、重なりに暗い接触線ができる。枝ごとに緑の族が 1 つ。実は半径 2.5 の小さな球で、葉より上に出る（berry だけ）。木の `Mass` は使わず、葉単位で組んだ。
- **丸太**: 横向きの解析的なカプセル（樹皮の斑は横に流れる、溝 3 本、上面に苔）と、年輪（髄・3 本の輪・樹皮の縁・ひび）の切り口。切り口は +x へ傾く平面。枝の切れ端が 1 本。
- **小岩**: 苔の敷き + 岩 2〜3 / 岩 + 小石。

## 色と法線

- 色は `art/palette.json` の固定 64 色のみ。アルベドは全色のヘッダ（≤64）。法線は 61 ベクトル + 発光の印 1、高さは 32 段（HEIGHT64 / B=128、粗さ 80%）。3 つの alpha 形は画素単位で一致させ、一致しなければ止まる。
- 明るさの変化は、輪郭（どの向きも同じ）、図形の接触線、平らな上面の苔、顔料の斑（低周波）だけ。左上・右下で系統的に変わる塗りは入れていない。
- 法線は図形の高さ式の勾配から、アルベドの色は使わずに求める。高さは世界高さ（岩 2〜12、結晶 〜19、葉 dome+0〜5、丸太 〜9）で、輝度から作らない。
- 画素単位の乱数（紙吹雪）は使わず、ノイズは 2〜9px の周期。

## 実行と確認

```
python art/build_primary_materials3.py                    # .review/v3/primary-materials/<sheet>/ だけに書く
python art/build_primary_materials3.py --sheet minerals
python art/build_primary_materials3.py --integrate        # 画像を見た後に root が実行
```

確認用の出力は `<sheet>/{albedo,normal,height}/`（atlas, contact, gif）と、朝・夕の 2 段の `lit/`。標準出力に、フレームごとの画素数・bbox・色数・法線数・発光画素・|r(L\*, 水平 N)| が出る。この相関は退行の検出用で、見た目の合格ではない。

`--integrate` の前に、manifest と既存 atlas の名前・順・64x56・pivot・枠の時間・タグ・列数を確かめる（違えば何も書かない）。全シートの検査が通ってから、`art/<sheet>.json`、`art/normalmaps/<sheet>-{normal,height}.json`、`assets/<sheet>/{atlas.png,atlas.json,normal.png,height.png}` だけを一時ファイル経由で置き換える。manifest は書き換えない。枠の時間とタグは既存の atlas から読む（全枠が静止 100ms・タグ `default`）。
