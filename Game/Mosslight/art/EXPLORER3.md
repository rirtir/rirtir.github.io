# Explorer3 — 制作途中の旧主人公（造形は採用取り下げ）

現在の状態: 4方向×12コマの48コマを実行・統合し、法線／高さのalphaと接地メタデータを検査した。ただし2026-10-06の最新ユーザー指示で主人公の造形は却下された。採用済みではない。`.review/v4/ART_BRIEF4.md` に従い静止画から再設計する。以下は旧工程の記録であり、旧頭身や「承認済み」という記述を新しい造形の採用条件に使わない。

## 実行

```
python art/build_explorer3.py            # down の12コマ。--dirs で方向を追加、--out で出力先を変更
```

出力は `.review/v3/explorer-production/` の `{albedo,normal,height}/`（atlas.png/json、contact.png、タグ別 gif（idle/walk/attack/roll）、review.html）、`{albedo,normal,height}.json`（Workbench のソース）、`poses.json`。`assets/` と正本は phase 1 では触らない。

## 方針

- 基準は承認済みの正面 `art/hero-static3.json`。部品の絵・配置・重なり順・パレットはそこから読み、新しい色が必要なら警告に出す（色の再定義はしない）。
- 腕は上腕・前腕・手、脚は太もも・すね・ブーツに分割。idle0 は承認済みの原画素をそのまま使うため、`poses.json` の `split_check.idle0_matches_approved` が true になるはず（コマ0の合成と承認済みコマ0の画素比較）。
- 承認済みの姿勢（hang / stand）から外れる手足は、そのコマの関節（肩・肘・手首／股・膝・足首）の間のカプセルとして描き直す。ビットマップの回転や行ずらしはしない。足を上げるブーツは、筒を1行縮めて靴底 #3b2a22 を2px出す。
- 上半身は胴・スカーフ・ポーチ（up）、頭と髪（head）、スカーフの尾（tail、相対 ≤1px）をそれぞれ平行移動する。呼吸・歩きの上下・攻撃の踏み込みは、この移動と骨盤（hips）で表す。
- roll0 は胴の胸4行を取り除く描き直し（しゃがみ）。roll1 は外套・髪・スカーフ・腕・ブーツを別々の楕円体として重ねた塊（直径約27、足の裏1行が見える）。roll2 は片膝を上げ、左手を地面（16,55）へ。
- ランタンは右手首に付ける（`wrist`）。攻撃・ロールでは腰（belt）に下げる。`poses.json` に手首と発光2画素の中心を記録するので、renderer 側の光源位置はそれを使う。
- 法線・高さ・粗さ: `build_hero_lightbox3` の `shapes/ell/hit/surface` を import して再利用（ファイルは変更しない）。動かした部品は新しい矩形で形を作り直し、手足は関節から作るカプセルにする。輝度は使わない。法線は 61方向の Lambert ベクトルのみ。外形に接する画素は傾き 0.8、内側は 0.45 までに制限。高さは 64 色以下、B=128 の中立ゲイン、ランタンのガラスだけ発光。
- 3つの atlas の alpha は同一のマスクから作る（外形1px は隣接する最前面の部品の形を借りる）。

## poses.json

コマごとに: `feet`（L/R の [x, y(靴底), P=接地/L=浮き]）、`feet_world`（pivot (24,58) 基準）、`joints`（肩・肘・手首・股・膝・足首）、`pelvis`、`head`、`grip`（攻撃のみ）、`lantern`、`checks`（接地足の靴底が y57-58、浮き足が地面から離れる、発光画素数、bbox、体の高さ）。

## 最初にやること（未確認）

1. 上のコマンドを実行し、例外とワーニングを読む（パレット外の色、キャンバス外のクリップ、`split_check`）。
2. contact.png を見て、idle0 と承認済み正面の一致、walk の左右対称と接地、attack の握り位置（`grip`）、roll の形を評価する。特に roll1 の塊の見た目、attack0 の折りたたんだ右腕、足を上げたブーツは粗い描き起こしで、見た目の判断はまだされていない。
3. 発光画素が2であること、normal の傾き上限、height 色数を `poses.json` と各 atlas で確認する。
4. 歩きの周期・足滑りはブラウザ再生と実ゲームで確認する（静止画では合格としない）。

## 既知の割り切り（phase 1）

- フレーム時間は暫定（idle 600、walk 110、attack 80/80/120、roll 100）。renderer の値に合わせて調整する。
- 手首の握りは doc の GRIP と一致させたが、腕の長さは骨長の厳密な拘束をしていない（カプセルは指定した関節間を結ぶだけ）。
- 外套の右端のはみ出し（attack1）は小さな追加画素のみ。
- 全48コマが揃った後に、正本の素材プロジェクト（部品クローン含む）を保存する。phase 1 では行わない。
