# 動作を含むビジュアル受け入れ

2026-10-08: 前回の静止画中心のレビューでは公開判断に必要な確認が不足していた。旧レビューの合格を、本手順の合格として引き継がない。

## 先に行うレビュー

通常の manifest、通常起動、実際の入力で確認する。候補アセットへの差し替えや人工的な整列シーンは原因調査にのみ使い、受け入れ証拠にしない。主人公の現行絵はユーザーの原画待ちの仮素材であり、絵の採用判定を行わない。

| 操作・条件 | 見るもの | 不合格となる現象 |
| --- | --- | --- |
| 新規開始直後から歩く、止まる、方向を変える | 地形境界・細部・影とカメラの関係 | 地面の形が変わる、世界に固定された細部が泳ぐ、描画方式の切替で景色が変わる |
| 四方向と斜め移動、森を横切る | 足元・遮蔽・樹冠・画面端の影 | 足が滑る、通行と絵が一致しない、影や木が突然消える |
| 暗い森で樹冠が重なる、GLから2Dへ切り替わる | 人物位置を示す輪郭と暗さ | 診断上は輪郭ありでも実画面で見失う、2Dの暗幕で位置表示が消える、表示のために人物や周囲が全面明るくなる |
| 同じ実景で9時・正午・15時、その間の連続変化 | 太陽方向、法線の受光面、地面への投影 | 朝夕で明暗面が入れ替わらない、影が足元だけに残る、影方向と受光方向が矛盾する |
| 17時から19時、23時、光源の設置と撤去 | 日没の推移・月明かり・局所光 | 太陽の明暗が夜にも残る、光源なしで十分に見える、光源が意味を持たない |
| 木の種類・左右反転・森の奥行き | シルエット・枝葉のまとまり・幹・材質 | 葉のノイズで形が読めない、全幹が同じ斜め形、反転で太陽向きが変わる、種類によって影が欠落する |
| 屋外から屋内、洞窟、画面サイズ変更 | 照明経路と遷移 | 屋根や光の不自然な残像、光源と受光位置のずれ、通常起動だけ別の描画になる |

## 証拠と判断

- 全画面の連続記録を残し、入力・経過時間・ゲーム時刻・カメラ位置・実際の照明方式を対応づける。
- 連続記録から短い間隔のフレーム列を実際に確認する。動画を再生して見ていない場合は「動画を視聴した」と記載しない。
- 境界や影は同じ世界座標に合わせたフレーム列でも比較し、カメラの平行移動と地形自体の変化を区別する。
- 通常起動の確認を済ませた後、法線・アルベド・高さ・影の診断表示で原因を切り分ける。強制GLや素材差し替えの結果は通常起動の結果と区別する。
- 各指摘に再現操作、画像の時刻・場所、原因、修正後に同じ操作を再実施した証拠を付ける。
- 独立レビュアーには合格を依頼せず、不合格条件と未確認事項の探索を依頼する。機能テスト数、数式の一致、担当者の自己申告だけでビジュアルを合格にしない。
- 不合格または未確認の必須項目が残っている段階で「完成」として公開しない。工数・使用量の停止は品質の合格と区別する。
