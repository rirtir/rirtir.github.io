編集範囲: `renderer.js`・`lighting.js`・`tests/visual_rework3.js`・`tests/index.html`・本書。**この環境にはスクリプト実行がなく、ブラウザ・テストは一度も実行していない。** 以下は「コードを書いた」記録で、動作確認済みではない。確認はルートが `tests/index.html` と撮影で行う。

## 第1段で配線済み（renderer.js / sky.js）
- `render()` が毎フレーム `skyAt(hourOf(clock), map.id, {arenaLift})` を **フレームの先頭で1回**呼び、GL・2D・腰の灯・2D接地影・統計が同じ値を使う（第2段で先頭へ移動。以前は描画後で、`drawShadows` は前フレームの `VS.sky` を見ていた → 解消）。
- `lightParams`: GL へ `sunDir/sunColor/sunStrength`（昼弧の外は厳密に 0）、`moonDir/moonColor/moonStrength`、`skyColor`、`lightScale = 1 − 0.8·dayness`。旧式は `TOG.skyModel=false` の時だけ。
- 太陽/月の投影影: `drawFrame` が sortList の描画中に height 画像の切り出しを記録（`capOn`、最大 192、要素は使い回し）→ `buildShadowBuffer` が足元の行を軸に傾けて `lighten`。向き・長さは `sky.shadow.vec`。
- 2D fallback: `lightPass` が `curtain2D(sky)`。GL の楕円接地影は半径 0.45 倍・ry≤2 に縮小（二重影の抑制）。

## 第2段で追加したもの
### 局所光（たいまつ・焚き火・腰の灯）の地面影 — lighting.js / renderer.js
- **lighting.js**: 影を持てる灯を 1 → 最大 `MAX_PT=3`。`uShadow2` は「灯ごとのセルを横に並べた影アトラス」。1セルは灯の**足元**を中心とする `2·PT_HALF=256` native px 四方（coarse は 0.5 倍）。シェーダは `uPtS[slot]`（足元 x,y / 光源の**実高さ** / 強さ）と `uPtSlot[灯番号]` で灯ごとに参照する。受ける面 `g` から `g + vg·hr`（`vg = (g − 足元)/光源の高さ`、長さ 1.6 上限）を読むので、**光源から遠ざかる側に影が伸び、光源側は照らされる**。窓の縁（半径の 75〜100%）で影を薄めて切れ目を作らない。法線の N·L は従来どおり灯の向きで計算するので、**反転した法線（`flipNormalX` 済みの資産）も光の側だけ明るくなる**。
- API: `render(..., { ptShadow: { canvas, cell, th, entries:[{light, x, y, h, strength}] } })`。`entries[j].light` は `lights` の同じオブジェクトで、packed 後の番号に対応づける（画面外・8灯超で切り捨てられた灯は影なし）。`stats.ptShadow / stats.ptShadows` に実際に影を持った灯の数。
- **renderer.js**: `addLight(..., src)` に物理光源 `{x,y,h}`（足元 world px と足元からの高さ）を追加。たいまつ h=40（先端）、焚き火・鍋 h=24、灯籠・燭台・噴水 h=20、腰の灯は足元から 12px。`buildPointShadows` が、主人公の灯を最優先、次に画面中心に近い順で最大 3 灯（coarse は 2 灯）を選び、**灯ごとに**遮る物の height 画像を「その物の足元が灯の足元から遠ざかる向き」へ傾けて `lighten` で描く。
- 上限・再利用: 遮る物は既存の 192 件の記録を共用（追加の記録・確保なし）。1灯あたり描画 `PT_MAX_DRAW=64` 件まで、灯の半径＋40px の外は描かない、灯自身の物（足元 10px 以内）は落とさない。canvas は `shpCv` 1枚を使い回し（サイズが変わった時だけ再確保）、灯の配列も使い回し。
- トグル: `TOG.pointShadows`（`projectedShadows` の下位）。`setVisualToggle('pointShadows', false)` で局所光の影だけ止められる。
- コンテキスト喪失/復帰・2D fallback は変更していない。影アトラスのテクスチャは `onRestored` で作り直される（既存処理）。

### 第3段: physical な局所光(src 付きの灯の幾何を1つに揃える)
- 問題: `addLight(ax, ay-16, …, src:{x:ax,y:ay,h})` の src.h を `packLights` が無視し、z は常に `14+0.12r`。シェーダの拡散は画面画素 `pp` と画面上の光の中心、投影影は地面位置 `g=pp+(0,h)` と足元・実高さを使っていて、拡散と影が別の光源位置を見ていた。
- 修正(lighting.js): src 付きの灯は `uLightPhys[i]=1`。`uLightPos` は足元の地面位置(x,y)・半径・**実高さ**。受ける面の地面位置 `g` から `Lv=(Δx, −Δy, H−h)`、距離減衰は**地面上の水平距離**。タイル遮蔽は `g+cam → 足元+cam`。height ray は地面座標と rayH を線形に進め、`screen y = 地面y − rayH` へ戻して height を読む。影スロットの `uPtS` も physical なら同じ足元・高さで上書き(entries がずれても1光源)。src 無しの灯は旧式のまま(`uLightPhys=0`、画面画素・中心・`14+0.12r`)で、既存のテスト・旧呼び出しは変えない。
- カリング: 足元基準。照らす地面は半径 r、受ける面の高さ(最大 64px)だけ画面上へ伸びるので、上側は `y−r−64 > H` で判定。
- renderer.js: 2D fallback の光の中心(`L.x,L.y`)は見える炎の位置 `ay−lampH`(たいまつ −40、焚き火・鍋 −24、他 −20)に変更。GL は src を使う。`handLight=false` は `pr=0` のまま光を出さない(旧 `amb<nightradius` の枝は復活させていない)。腰の仮スプライトは据え置き。
- 固定の太陽・half-Lambert・非照光面のブーストは入れていない。
- テスト(`visual_rework3.js` (d)): L.x/L.y をわざと (10,10) にして足元の左右が鏡像、地面でも向きが一貫、実高さで平地の照度が変わる、高さ20pxの面は手前の光で明るく後ろで暗い、実高さが面より低いと暗い、entries を大きくずらしても影が光源の足元に出る。**ブラウザ未実行**。
- 近似の弱点(正直に): height ray は画面の1枚の height 画像を数ステップ(最大8)で辿るだけ。1画素に1つの高さしか無いので、物の裏側・屋根の下・重なった物は読めず、薄い物や細い柱はステップの間をすり抜ける。地面座標で辿る時に読む画素は「地面位置を rayH だけ上へ戻した点」で、奥の高い物の上面が手前に見えている場合などで誤って遮る/通す。ビルボードの足元や、受ける面の `g` を高さから逆算する近似(法線の向きと高さが資産の推定値)にも依存する。完全な3D影ではなく、ゲーム全体の完成宣言でもない。

### 腰の手提げ灯 — renderer.js
- 見える腰の灯を描く時だけ光る。地上で `TOG.handLight` かつ `dayness<0.9` の間、主人公の腰（足元の 12px 上、向きで左右 ±5px）に 3×5px の灯（暗い枠＋琥珀のガラス 1×3）を `drawHero` が描き、ガラスだけ法線 B（自発光 0.63）で光らせる。光源の位置（半径 1.6 タイル・power 0.35、弱いまま）はこの灯と同じ点。地下は従来どおり主人公の中心の常時光（腰の灯は描かない）。
- 主人公のシェーダは変えていない（主人公の全体を光らせる処理はない）。灯の絵は手書き fillRect の仮のもので、**正式なドット絵ではない**（アセットは触っていない）。

### 2D fallback の方向つき接地影 — renderer.js
- GL を使わない時、`drawShadow` が楕円を `sky.shadow.vec` の向きへずらし、横に伸ばす（長さは楕円の ry に比例、最大 10px）。夜（月の影）は弱い向き、地下・影なしは従来どおり。GL 時は従来どおり縮小接地影のみ。

## テスト（tests/visual_rework3.js、`tests/index.html` から実行。純ブラウザ・アセット不要）
- 空（`sky.js` 実関数）: 19/23 時の太陽 0、23 時の板 ≤10 で無彩色に近い、19 時は 28 未満、17 時の暖色（R−B≥30・太陽色 R/B≥1.6）、午前と午後で影の向き（vx の符号）が反転、正午は影が短い、15 分刻みで向きが飛ばない、地下。

- GL 合成（**WebGL2 がある時だけ**。無ければ「SKIP」と明記して `result.skipped` に残す。合格とは数えない）: 12/17/19/23 時の板が `skyAt` の表示値に ±4 で一致、23 時は各チャンネル ≤10。点光源は光に向く法線が背く法線より明るい、鏡像の左右対称（±3）、半径の外は暗いまま、影アトラスの座標対応（足元の右の窓内は 75% 未満に暗くなり、反対側は不変）。
- 足元: 当たりの楕円が正で、アンカーの近く。`FOOTPRINTS` を一時的に差し替え、**反転した木は足元の中心が −dx、反転しない木は +dx にずれる**（実データのノード）。ノードの衝突そのもの（歩行の押し戻し）は既存の `gameplay.js` の領域で、ここでは足元の幾何だけを見る。

1. **ブラウザ未実行**。構文・実行時エラー、shader のコンパイル（`uPtS[]` `uPtSlot[]` の動的インデックス、`#define PT_HALF`）、影の向きの符号、`lighten` の見た目はすべて未確認。コンパイルに失敗すると `createLighting` が null を返し 2D 照明になる（既存の防御）。
