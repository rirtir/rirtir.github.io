# ANCHOR//VECTOR — アートガイド

- 版: 1.1（プレイテスト視認性改修）
- 目的: 画像、3D、UI、演出、音響の判断を一つの視覚言語へ統一する。

## 1. アートコンセプト

`青い航路盤に浮かぶ敵核を見抜き、静かな計画を一閃へ変える。`

宇宙は濃紺で保つが、操作面は一段明るい青いジオラマとして常時見せる。情報量を形、明度差、限定的な発光で整理し、小画面でも敵、弱点、経路、危険、安全、奥行きを一目で区別できることを最優先する。

## 2. 世界の造形

- 時代感: 人の姿が消えた後の遠未来軌道施設。
- 建築: 巨大な環、分割された梁、浮遊する六角床、用途不明の航路灯。
- 美術語彙: 航法機器、セラミック装甲、黒い金属、切断面、同心円、欠けた軌道。
- 禁止: 現代銃器、軍用迷彩、錆だらけの廃墟、密集した配管、読めない装飾文字、過剰な汚し。
- 画面密度: 主役1、敵最大8、背景大形状3〜7。微細ディテールより輪郭を優先。

## 3. 色彩規定

### 基本色

| 役割 | 色 | 用途 |
|---|---|---|
| Void | `#07111F` | 最深背景 |
| Deep Navy | `#10243A` | パネル、宇宙 |
| Slate | `#314A63` | 構造物、敵外装 |
| Ceramic | `#DCE7E5` | プレイヤー外装、主要文字 |
| Muted Text | `#91A3AE` | 補助文字 |
| Player Cyan | `#43F5D0` | プレイヤー、確定経路、安全 |
| Route Blue | `#42B8FF` | 計画中経路、選択ノード |
| Enemy Coral | `#FF5E73` | 敵中枢、HP |
| Danger Amber | `#FFB84A` | 予告、注意、未確定 |
| Critical Violet | `#B889FF` | ボス、異常空間、CORE |

### 色のルール

- 赤/珊瑚色は敵本体と実害が確定した危険だけに使う。
- 黄/琥珀は予告と選択確認。ダメージそのものには使わない。
- シアンはプレイヤーが利用可能なものだけに使う。
- 色だけで区別せず、敵=菱形/角、危険=三角マーカー、安全=円環を併用する。
- 発光面積は画面の15%未満。常時全面ブルームは禁止。

## 4. 形状言語

- プレイヤー: 前方へ絞られたレンズ/矢尻。滑らかな曲面と白い外装。
- アンカーノード: 円、円環、球。安全で中立。
- 通常敵: 三角、菱形、刃。攻撃方向が輪郭から分かる。
- ボス: 完全形に近い多面体や同心円。通常敵より規則的で巨大。
- 背景: 欠損した円弧、六角柱、長い梁。敵と競合する小さな尖りを避ける。
- UI: 角を斜めに切った長方形。角丸は4px以下。カードのみ8px。

## 5. マテリアル

- プレイヤー: 低粗度の淡いセラミック、シアンの内部発光、黒い関節。
- 敵: 中明度の青灰金属、珊瑚色の内部発光、常設の珊瑚色ターゲット環。真黒は禁止。
- ボス: 黒金属70%、陶磁質20%、紫発光10%。
- 背景: 高粗度、低彩度、発光は航路灯だけ。
- 透明材は経路線、シールド、予告面に限定する。
- 写実PBRテクスチャは使用せず、頂点色、単色、簡易ノイズで表現する。

## 6. 3Dモデル一覧と規格

全モデルは `models.js` でThree.jsプリミティブを階層化して生成する。外部モデルファイルは必須としない。

### プレイヤー

- LANCER: 長い菱形胴体、左右2枚の薄翼、後部二重リング。
- WEAVER: 三つ葉状の外装、中央球、周囲に3基の小型アンカー。
- BULWARK: 扁平な六角盾、厚い外周、中央レンズ。
- 共通寸法: 直径0.9〜1.3m。画面上で最小24CSS pxを維持。

### 通常敵

- SEEKER: 眼球状コア+3枚フィン。
- LANCER: 細い八面体+長い発射軸。
- WARDEN: 半円盾+背面コア。
- BLOOM: 5枚花弁+機雷カプセル。
- TETHER: 二叉アーム+中央リール。
- MIRROR: 向かい合う2枚の鏡面刃。
- FORGE: 立方体母機+開閉シャッター。
- NULL: 黒い正八面体+紫の内核。

### ボス

- RING WARDEN: 3軸の欠けた環、中央3核、外径7m。
- TETRA CROWN: 四面体フレーム、4面砲台、外径6m。
- VESPER CORE: 球核、6本の軌道弧、浮遊する記録片、外径8m。

### 環境

- 外縁: 細い梁、航路灯、白い破断面。青緑寄り。
- 断層: 六角岩盤、断線したケーブル状曲線、琥珀の微光。
- 中枢: 同心円床、黒い鏡面片、紫の脈動。
- ジオメトリ予算: 通常戦場表示10万三角形未満、ボス戦15万未満。
- ドローコール目標: 通常100未満、最大180未満。

## 7. カメラと画面構成

- 基本: 透視投影、焦点距離相当45〜55mm、俯角25〜35度。
- プレイヤーと次の経路終点を含むよう緩やかに自動フレーミング。
- 実行中は移動方向へ最大8%先行し、回転は最大12度。急激なロールは禁止。
- ボス登場時のみ1.2秒の引き。操作可能になる前に通常構図へ戻す。
- 縦画面ではカメラ距離を引き、上下UIの安全域を避ける。
- 背景梁と破片は必ず戦闘面より奥へ置き、敵、機体、アンカーを遮らない。

## 8. UIデザイン

### タイポグラフィ

- フォント: OS標準ゴシック。`system-ui, -apple-system, "Segoe UI", "Noto Sans JP", sans-serif`。
- 英数字見出し: 太字、字間0.08〜0.16em、大文字。
- 日本語本文: 400〜600、行高1.6。
- 最小本文14px、主要操作16px、タッチボタン内16px以上。

### HUD

- 左上: シールド3枚を大きな弧で表示。
- 上中央: 遭遇数、敵残数、ボスHP。
- 右上: 一時停止。
- 左下: FLOW円環。
- 右下: OVERTRACE。使用可能時のみ強く発光。
- 計画中: `HIT` と赤い `CORE` の予測数、危険予測を経路付近へ直接表示。
- 上中央: 使用経路数とPARを常時並記し、少ない一筆という上達目標を示す。
- 常時説明文を置かず、戦場を最大化する。

### アイコン

- 24×24基準、線幅2、端部は角または短い丸端。
- 単色SVG。塗りつぶしと線の混在を避ける。
- 必須: 戻る、設定、音、振動、全画面、保存、読込、削除、一時停止、再開、シールド、FLOW、CORE、FRAGMENT、各機体、各モジュール系統、各モード。
- アイコンに文字を焼き込まない。

### タッチ

- 最小操作領域48×48CSS px、主要ボタン56px。
- `env(safe-area-inset-*)` を全固定UIへ反映。
- 指の直下に重要文字を出さず、経路情報は接触点より32px上へ配置。

## 9. 演出

- 計画開始: 彩度を15%落とし、音をローパス、ノードの輪郭を強調。
- 経路確定: 50msの白シアンフラッシュ。全画面白塗りは禁止。
- 斬撃: 進行方向に薄い板状残像、火花8〜18個、0.08秒のヒットストップ。
- クリティカル: 紫を混ぜず白+シアンで二重線。
- 被弾: 珊瑚色の六角亀裂、軽い色収差風ずれ。画面揺れ最大5px。
- 敵撃破: 外装を3〜6片へ縮退消滅。剛体破片は使わない。
- VECTOR SEAL: 閉じた面を0.25秒だけ半透明表示し、内側へ収束。
- FLOW段階: 残像長とBGMレイヤーを段階追加。ブルーム増加だけで表現しない。
- Reduced Motion時: カメラ先行、揺れ、残像を無効化し、色と輪郭で結果を示す。

## 10. キービジュアル

- 用途: タイトル背景、ポータル紹介用、OG候補。
- 構図: 横長。中央やや下にLANCER、暗い軌道遺跡を斜めに貫くシアンの三角経路。遠景に三重リングボス。
- 文字は画像へ入れない。タイトルはHTMLで重ねる。
- 色: Void/Deep Navy 75%、Slate/Ceramic 15%、Cyan 7%、Coral/Violet 3%。
- 画風: 洗練されたローポリ3Dコンセプト、硬質、静かな宇宙。人物なし。

## 11. 音響ガイド

- 音楽: 72〜108 BPM相当の生成型アンビエント・テクノ。低いパルス、ガラス質FM音、細いノイズ。
- 計画中: ローパスを下げ、拍を間引く。完全停止させない。
- FLOW25/50/75でハイハット、アルペジオ、上声部を追加。
- 通常戦闘、ボス、ハンガーの3状態。旋律は短い音型を共有する。
- UI: 乾いた短音。決定=上行2音、取消=下行1音、警告=低い二連。
- 斬撃: 帯域制限ノイズ+短いサイン波降下。被弾: 金属ノイズ+低音。
- 音量基準: BGMを効果音より6〜9dB低く感じるバランス。
- iOSの音声開始制限に合わせ、最初の明示的タップでAudioContextを開始する。

## 12. 検品基準

- 160px幅の縮小表示でもプレイヤー、敵、経路、危険が区別できる。
- グレースケールでも形状で敵味方を判別できる。
- 発光を切ってもシルエットと明度差が残る。
- UIと3Dで同じ色の意味が逆転しない。
- 生成画像に文字、透かし、第三者ロゴ、画風逸脱がない。
- すべての必須要素が `ASSET_MANIFEST.md` に対応する。
