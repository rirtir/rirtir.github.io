## 1. 開発方針

この文書はゲーム内容だけでなく、制作判断、品質基準、再開手順を固定する。会話履歴へ依存せず、このフォルダだけで開発を再開できる状態を常に維持する。

### 1.1 ユーザー要求

- GitHub Pages上で動作し、サーバー、ログイン、外部APIを必要としない。
- スマートフォンを基本操作環境とする。
- セーブ機能を必須とする。
- 3Dモデル、画像、音響を含む必要素材は開発側で制作する。
- ゲーム仕様、アートガイド、素材制作、実装、検証、追加要素監査の順で進める。
- 途中で提案可能な要素は原則として仕様へ吸収し、完成までユーザー判断を要求しない。
- 区切りではなく完了条件で終了を判断する。
- 進捗は `ROADMAP.md`、素材は `ASSET_MANIFEST.md`、品質は `QA_CHECKLIST.md` で追跡する。

### 1.2 技術制約

- ビルド工程なしのHTML/CSS/JavaScript ES Modules。
- Three.jsをローカルに同梱し、CDN停止に影響されない構成とする。
- 3Dモデルはコードで組み立てる手続き型ローポリメッシュとし、外部DCCを必須にしない。
- 画像は生成したキービジュアルをローカル同梱し、UIアイコンは画風を保証できるSVGまたはCSSで制作する。
- BGMと効果音はWeb Audioでリアルタイム合成し、音源ファイルや権利処理を不要にする。
- 通信がなくても、初回ロード済みの同一ページ内では全機能が動作する。
- 保存データはlocalStorageへバージョン付きJSONで保存し、主キー・バックアップキー・入出力を持つ。

## 2. 製品定義

### 2.1 タイトル

`ANCHOR//VECTOR`（アンカー・ベクター）

副題: `星環の残響`

### 2.2 ジャンル

一筆経路型3Dアクション・ローグライト。

### 2.3 一文説明

時間を遅くして立体空間に攻撃経路を描き、指を離すと無人機が高速で敵を斬り抜ける、思考時間を保証したスマートフォン向け3Dアクション。

### 2.4 設計柱

1. **操作は静か、結果は激しい** — 入力中は考えられ、実行時に強い速度感と破壊感を出す。
2. **一本指で完結** — 仮想スティック、手動照準、手動カメラ、複数ボタン同時押しを要求しない。
3. **3Dを攻略に使う** — 前後・上下・遮蔽物・回転構造・包囲経路が戦術へ直結する。
4. **上達と研究が残る** — 恒久的な数値上昇より、経路技術、装備の横幅、制約攻略をやり込みにする。
5. **短い再挑戦** — 1戦40〜90秒、1出撃8〜15分。失敗しても知識と一部資源が残る。

## 3. 対象環境

- 主対象: iOS Safari、Android Chromeの現行系、タッチ操作。
- 副対象: デスクトップChrome/Edge/Firefox、マウス・キーボード。
- 画面: 縦横両対応。横画面推奨だが回転強制はしない。
- 最小CSS表示領域: 320×568、568×320。
- 基準性能: 中級スマートフォンで30fpsを下限、一般的なPC/上位スマートフォンで60fpsを目標。
- WebGL 2非対応時は、理由と対応案を示す専用エラー画面を表示する。

## 4. 世界設定と物語

### 4.1 前提

無人軌道施設「VESPER RING」は、恒星風災害の直前に自らを分解し、居住圏への落下を回避した。長い休眠の後、保守機AV-7が再起動する。目的は散逸した記録核を回収し、リングの最後の命令を完了すること。

### 4.2 表現方針

- 会話、固有人物、長文イベントは使用しない。
- プレイヤー機は人格を持たず、説明不足を感情的独白で補わない。
- 物語はタイトル、セクター名、全12件の短い記録、通常エンド、深度12エンドだけで完結する。
- 記録文は実装時に新規創作せず、以下をそのまま使用する。

### 4.3 固定記録

1. `環状暦 0000 — 保守系統、応答。居住信号、なし。`
2. `分離命令は外部からではない。リング自身が選んだ。`
3. `落下を避けるには、ひとつであることをやめる必要があった。`
4. `切断された区画は、それぞれ別の夜を回り続けている。`
5. `回収機は記録を運ぶ。記録は回収機を帰還させない。`
6. `航路灯は消えていない。見る者がいなくなっただけだ。`
7. `中枢は救難信号を送らなかった。代わりに座標を消した。`
8. `最終乗員数、零。最終退避艇数、全艇。`
9. `破壊ではなく退避。敗北ではなく選択。`
10. `リングは都市を救うため、自らを空から除外した。`
11. `残響は命令ではない。完了を待つ記録である。`
12. `AV-7、全核を確認。最後の仕事は、帰還ではなく停止。`

### 4.4 エンディング

- 通常エンド: 深度0の中枢ボス撃破後、回収した核からリングの分離が避難成功のための自律判断だったと判明。AV-7は残骸の軌道修正を継続する。
- 真エンド: 深度12クリア後、全残骸が安全軌道へ移り、AV-7が航路灯を消して停止する。最終表示は `TASK COMPLETE / NO RETURN REQUIRED`。

## 5. コアルール

### 5.1 戦場

- 1戦場は直径20〜32m相当の浮遊ジオラマ。
- 空間ノード6〜12個、敵2〜8体、障害物0〜5個で構成する。
- プレイヤーは空中停止でき、自由歩行しない。
- カメラは戦場中心を自動追跡する固定寄りの透視投影。任意の二本指ドラッグ/右ドラッグで±35度だけ補助回転できる。

### 5.2 経路入力

1. 画面の任意位置を押すと計画状態へ入り、ゲーム時間が設定値まで低下する。
2. 指に最も近い選択可能ノードを、CSSピクセル基準の吸着半径内で経路へ追加する。
3. 選択可能数は基本3点。現在地点を含めず、同じ点の連続選択は不可。
4. 経路線、消費チャージ、交差する敵、着地点の危険予測を即時表示する。
5. 指を離すと経路を実行する。開始地点へ戻すか、UIキャンセル領域へ入れると取消。
6. `pointercancel`、画面回転、アプリのバックグラウンド化では誤発進せず取消。

### 5.3 時間

- 通常速度: 1.0。
- 計画中: 標準0.16。設定で0.08 / 0.16 / 0.25。
- 経路実行中: 1.0。1区間0.16〜0.28秒。
- 被弾直前の自動停止は行わないが、全攻撃に読みやすい2.5秒以上の予告を設ける。
- 高難度でも予告時間の下限は1.8秒を割らない。

### 5.4 攻撃

- 経路の線分と敵の当たり球が交差すると斬撃ダメージ。
- ノードとして直接選択した敵弱点にはクリティカル倍率1.5。
- 同一行動で2体以上を斬るとCHAINが増加。
- 始点近傍へ戻り三角形以上を閉じるとVECTOR SEALが発動し、囲まれた敵へ範囲ダメージ。
- 敵正面の盾は通常斬撃を80%軽減。背面または盾の外側から交差すると無効化。

### 5.5 防御と失敗

- プレイヤーはシールド3枚。被弾1回につき原則1枚を失う。
- 被弾後1.2秒無敵。連続多段死を防止する。
- シールド0で被弾すると戦闘敗北。
- 敗北時はその出撃で得た未確定資源の50%を失う。初回チュートリアルでは喪失なし。
- 戦闘再挑戦は1出撃1回。広告、課金、通信による復活はない。

### 5.6 FLOW

- 連続撃破、弾体へのニアミス、弱点攻撃、VECTOR SEALで上昇。
- 被弾、6秒以上攻撃なしで低下。
- 0〜100。25/50/75で演出と報酬倍率が段階上昇。
- FLOW100で必殺技 `OVERTRACE` を使用可能。直前の経路を残像が逆走し、再攻撃する。

## 6. 出撃構造

- 1出撃は最大7遭遇。
- 遭遇1〜2: 外縁、3〜4: 断層、5〜6: 中枢、7: ボス。
- 2戦目と4戦目後に「帰還して資源確定」または「潜行して報酬倍率上昇」を選ぶ。
- 戦闘後は3候補からモジュールを1つ取得する。
- 戦闘、エリート、修復、記録、異常空間の遭遇種別をシード生成する。
- 通常出撃はシードを保存し、中断再開可能。戦闘途中は戦闘開始状態から再開する。

## 7. 機体

### AV-7 LANCER

- 初期機体。直線経路と弱点攻撃が得意。
- 固有: 10m以上の線分の最初の命中がクリティカル。
- 必殺補正: OVERTRACEの復路速度+25%。

### AV-3 WEAVER

- VECTOR SEALと残留ワイヤーが得意。
- 固有: 閉じた経路の必要頂点を3から2へ軽減。ただし直撃威力-15%。
- 解放: 通常エンド到達。

### AV-9 BULWARK

- 衝突と防御が得意。
- 固有: 計画開始から0.5秒間は正面弾を無効化。移動速度-10%。
- 解放: 深度3クリア。

## 8. 敵・ボス

### 通常敵

1. SEEKER — 追尾弾。球形、単眼。基本教材。
2. LANCER — 直線予告後に貫通射撃。細長い菱形。
3. WARDEN — 正面盾。背後経路を要求。扇形装甲。
4. BLOOM — ノードへ時限機雷を設置。花弁形。
5. TETHER — ノード間を封鎖。二叉形。
6. MIRROR — プレイヤーの前回経路を遅れてなぞる。双面形。
7. FORGE — 小型SEEKERを生成。箱形母機。
8. NULL — 計画減速率を一時的に弱めるエリート。黒い正八面体。

### ボス

1. RING WARDEN — 三重回転リング。開口を経由して3核を破壊。
2. TETRA CROWN — 四面体の各面が攻撃パターンを持ち、戦場全体を回転。
3. VESPER CORE — 過去経路を複製し、最終段階では安全ノードが周期変化。

## 9. モジュール

24種を完成版必須数とする。レア度はCOMMON / RARE / CORE。重複取得時は段階強化。

### STRIKE

- LONG EDGE: 8m以上の線分威力+25/40/55%。
- SECOND CUT: 同一行動2体目以降+20/35/50%。
- BACK TRACE: 背面攻撃後、次の線分+30/50/75%。
- PIERCER: 盾への軽減率を20/35/50%減少。
- EXECUTE: HP25%以下への威力+40/70/100%。
- FIRST LIGHT: 各戦闘の初撃が2/2.5/3倍。

### WIRE

- LIVE WIRE: 経路が2/3/4秒残り、接触ダメージ。
- SMALL SEAL: SEAL範囲+20/35/50%。
- CLOSED CIRCUIT: SEALごとにFLOW+8/12/16。
- TENSION: 折れ角が鋭いほど威力上昇。
- AFTERLINE: 1.4/1.1/0.8秒後に経路を残像が再走。
- SNARE: 同じ敵を一周すると2/3/4秒停止。

### IMPACT

- CARRY: 小型敵を終点方向へ運ぶ。
- COLLIDER: 敵同士の衝突威力+50/90/140%。
- WALLBREAK: 12m以上の長距離経路の終点で範囲ダメージ。
- SHOCK ARRIVAL: 終点に衝撃波。
- HEAVY VECTOR: 経路速度-10%、威力+35/55/80%。
- KINETIC SHIELD: 12m以上移動後、1回だけ被弾無効。

### FLOW

- NEAR MISS: ニアミスFLOW+50/80/120%。
- MOMENTUM: FLOW50以上で経路点+1。
- OVERCLOCK: FLOW75以上で速度と威力+20/30/40%。
- REVERSE: OVERTRACE復路威力+35/60/90%。
- CALM CORE: 計画中の敵時間をさらに15/25/35%低下。
- LAST SIGNAL: シールド1でFLOW低下なし、威力+25/40/60%。

## 10. 恒久進行とモード

### 資源

- `FRAGMENT`: 出撃報酬。帰還判断で確定し、外見色の解放に使用。
- `CORE`: ボス撃破の証明。希少な外見色の解放にFRAGMENTと併用する。

### 解放

- 初期: LANCER、標準出撃、モジュール12種。
- 通常エンド: WEAVER、デイリー、残りモジュール6種。
- 深度3: BULWARK、エンドレス、残りモジュール6種。
- 深度6: ボスラッシュ。
- 深度12: 真エンド、最終外見。

### 難度深度

- 深度0〜12。
- 敵HP・速度だけでなく、編成、同時予告、エリート特性を段階追加。
- 深度ごとに固定変異を明示し、不透明な補正を使わない。

### デイリー

- ローカル日付から決定的シードを生成。
- 機体、モジュール候補、遭遇列を固定。
- オンラインランキングはない。自己ベスト、連続参加、達成メダルを保存。

### 実績（完成版20件）

- 初回撃破、初回帰還、初回ボス、各機体クリア、各ボス撃破、深度3/6/9/12、CHAIN10/20、SEAL同時4体、ノーダメージ、モジュール図鑑50%/100%、全記録、デイリー7日、エンドレス20戦、全機体深度6。

## 12. チュートリアル

- 4面、合計3分以内。
- 1: 押して時間を遅くし、ノードへ線を引く。
- 2: 敵を横切って斬る。
- 3: 赤い予告線から安全ノードへ移る。
- 4: 三角形を閉じてVECTOR SEALを発動。
- 説明は一度に2行以内。操作成功を検出して進む。スキップ・再受講可能。

## 13. セーブ仕様

- 主キー: `anchorVector_save_v1`
- バックアップ: `anchorVector_save_v1_backup`
- 一時キー: `anchorVector_save_v1_tmp`
- 保存前に現データをバックアップへ複製し、一時キー検証後に主キーへ確定する。
- 保存内容: schemaVersion、更新日時、設定、解放、資源、実績、記録、統計、各モード自己ベスト、中断出撃。
- 起動時に主キーを検証し、破損時はバックアップから復旧。両方破損時は初期化前に通知。
- JSON書き出し、貼り付け/ファイル読み込み、全消去を実装する。
- 中断出撃は戦闘開始時点の状態へ巻き戻す。乱数状態を保存し、再読込による候補変更を防ぐ。

## 14. アクセシビリティ・設定

- 計画速度: ゆっくり / 標準 / 速め。
- 通常ゲーム速度: 80% / 100%。報酬差なし。
- 高コントラスト、色覚補助記号、画面揺れ、残像、パーティクル量、描画倍率。
- BGM / 効果音 / マスター音量、ミュート。
- 振動、左右UI、二本指カメラの有無。
- チュートリアル再受講、全画面、セーブ管理。
- `prefers-reduced-motion` と `prefers-contrast` を初期値へ反映。
