## 先に伝えておくこと
- **`common-style.css` を読めませんでした。** ファイルツールが作業ディレクトリ外を拒否するためです。CONTEXT.md の記述だけを頼りに、`body.emberveil` と `.game-app` 配下で防御的に上書きしています。共通CSSの hover 等が詳細度の高い指定でボタンに効いている場合は、見た目が崩れる可能性があります。

## DOM契約

**表示の基本ルール**
- 表示/非表示は `hidden` 属性だけで切り替えます。CSSに `[hidden]{display:none!important}` を入れてあり、`dialog` は `[open]` 時のみ表示します。
- 初期状態は `#loading-screen` だけが表示で、それ以外のオーバーレイは `hidden` です。
- `#game-app` の補助属性は次のとおりです。見た目に効くため、ui.js が設定してください。
  - `data-touch="on|off"`
  - `data-hand="right|left"`
  - `data-reduced-motion="on|off"`（実効値）
  - `data-modal="open|none"`
  - `data-dialogue="open|closed"`（`open` でタッチUIを隠します）

**ゲーム画面・通知**
- `#world-canvas`: 全画面canvas。`tabindex=-1` で、Esc後のフォーカス復帰に使えます。

## レイアウトの要点
- 余白はすべて `env(safe-area-inset-*)` と `--pad` の大きい方です。
- 縦向きでタッチ操作中は、ホットバーが最下段で、その上にスティックとボタンが載ります。通知とボス体力は、状態・目標とミニマップの行の下に出ます。
- 横向きでは、スティックが左、ボタンが右、ホットバーが中央下です。
- 高さ520px以下（スマホ横）ではツール4個がミニマップの左に縦並びになり、タイトルは左右2カラムになります。
- スクロールするのは `#modal-body` とタイトルの縦あふれ時だけで、body は固定です。
- 動きの抑制は OS 設定と `data-reduced-motion="on"` の両方に対応しています。`off` を明示すれば OS 設定を上書きできます。
- 外部フォント・CDN・絵文字・静的な背景画像は使っていません。

他のファイルは変更していません。
