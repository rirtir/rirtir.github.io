# 統合で確認する事項

これは実装中の静的確認メモです。担当の書き込みが完了してから、ブラウザで再現を確認し、必要な修正を適用します。

以下の事項は統合と独立レビューで確認・修正済みです。検証の再現方法は `../tests/`、最終結果は `validation.json`、具体的な修正は `review-log.md` に記録しています。未対応の旅人選択はUIから除き、動作する機能だけを公開しています。

- 保存ロックの `ensure()` は、他タブの所有者が期限切れのときも旧タブが上書きしないこと。古いタブが復帰して最新スナップショットを上書きする経路を検証する。
- `App.checkOwner()` の例外経路が進行・保存を許可しないこと。
- 新規ゲームの `newGame()` が最初の保存に失敗しても、作成済みの世界をプレイ・JSON書き出しできること。
- メニューのキー表示とDATA.KEYBINDS/main.Inputの割り当てを一致させる。タイトル外枠の遊び方は暫定だった。
- 外枠の旅人選択（4種類）が実際の描画・保存に対応するか、未対応なら選択UIを残さないこと。
- 炉心2×2の原画を4回描かないこと。資源のspent/stump状態に応じた原画を描き、各資源の実体と見た目を一致させる。
- UIの設定でreduceMotion、音量、難易度、zoom、touch、予告強調、数値表示、UI倍率が本当に変わること。
- PC/スマホ縦/スマホ横のクラフト・インベントリ・設定・箱・ボス戦の各画面を確認する。
