# グラビティゴルフ

惑星の重力でボールの軌道が曲がる宇宙ゴルフ。ドラッグして引っぱり、はなして発射。
スイングバイ・ワームホール・ブーストリング・ブラックホール・自転する星を乗りこなして、
4コース × 9ホール = 全36ホールを攻略する。

公開URL: `https://rirtir.com/Game/GravityGolf/`

## 遊びかた

- **発射**: 画面のどこでもいいのでドラッグ → 引っぱるほど強く飛ぶ。はなすと発射
- **ゴール**: 旗の立った金色のリングにボールを入れる
- 惑星・リペラーには**着地**できる（ゆっくり触れると止まる）。そこから次の一打を打つ
- **太陽**に触れる／**ブラックホール**の中心に落ちる／場外 → 打った場所からやり直し（打数はそのまま）
- 打数がパー以下なら ★3。ベストスコアは自動保存
- ショートカット: `R` リトライ / `G` 軌道ガイド / `M` サウンド / `Esc` ホール選択

## ギミック

| ギミック | 挙動 |
|---|---|
| 惑星 | 引力。着地可能。公転しているものもある（着地すると一緒に動く） |
| 自転する星 | 着地すると回転に乗って運ばれる。発射時は表面の回転速度が上乗せされる。着地判定も表面との相対速度基準 |
| リペラー（紫） | 反重力でボールを押しのける。着地は可能 |
| 太陽 | 強い引力＋接触で焼失 |
| ブラックホール | 超強力な引力。中心核に触れると消滅。表面はなく素通りできる |
| ワームホール | 対になった出口へワープ（速度そのまま） |
| ブーストリング | くぐると1.5倍加速。1打につき各リング1回 |
| 公転ゴール | コース3にはゴールリング自体が公転するホールがある |

## ファイル構成

```
index.html   画面構造（HUD / タイトル / コース・ホール選択 / クリア画面）
style.css    スタイル（ダーク宇宙テーマ）
levels.js    全27ホールのレベルデータ（厳密なJSONリテラル・形式は先頭コメント参照）
physics.js   決定論的物理エンジン（GGP）。ゲームと軌道予測が共用
game.js      ゲーム本体（描画・入力・進行・演出・WebAudio合成サウンド）
```

## 開発メモ

- 物理は固定タイムステップ（1/240s）の決定論的シミュレーション。
  軌道予測（エイム中の点線）は同じエンジンで未来を先読みしているので、
  公転する天体のタイミングも含めて正確。
- **全27ホールのクリア可能性と最小打数は、physics.js と同じ挙動を
  Python + numpy で再実装したソルバー（角度×強さ×発射タイミングの総当り
  ＋着地点からの多段探索）で機械的に検証済み。** パーはその結果
  （最小打数と解の本数＝難易度）をもとに設定している。
  physics.js の定数やロジックを変えたときはソルバーでの再検証を推奨。
- 効果音はすべて WebAudio でリアルタイム合成（音声ファイルなし）。
  画像アセットもなし（惑星はシード値からプロシージャル描画）。完全クライアント完結。
- セーブは localStorage キー `gravityGolf_v1`。
