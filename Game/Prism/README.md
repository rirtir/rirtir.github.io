# PRISM — 光を導くパズル

鏡・ハーフミラー・フィルタ・プリズム・ガラス板・ガラス玉・ブラックホールで光を操り、**同じ色の受光器**まで届ける光学パズル。
光は 400〜700nm を 32 本の波長に分けて 1 本ずつ追跡しているので、プリズムでは本当に虹に分かれ、混ぜれば色が混ざります。

- 公開先: `https://rirtir.com/Game/Prism/`（`Game/Prism/index.html`）
- 技術: 素の HTML/CSS/JS（ES Modules）＋ WebGL2。ビルド不要・外部アセットなし（画像も音源もすべてコードで生成）
- 合計 約 230KB

## 遊び方
| 操作 | 内容 |
|---|---|
| ドラッグ | パーツを移動（0.25 グリッドにスナップ、Alt で解除） |
| 回転ハンドル | 回転（2.5° 刻み、Shift で 1° 刻み） |
| ホイール | 回転（5° 刻み、Shift で 2.5°、Ctrl で 15°） |
| Q / E | 微回転 |
| 矢印キー | 微移動（Shift でさらに細かく） |
| Tab | 次のパーツを選択 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| H | ヒント（解の位置を点線で表示） |
| Esc | ポーズ |
| 2 本指 | タッチでの回転 |

すべての受光器が点灯（色が合って、他の色が混ざっていない）したらクリア。固定パーツは回転だけできるものと、完全に固定のものがあります。
スマホ縦持ちでは盤面を 90° 回転して画面いっぱいに表示します（ストックは右側。iOS の左端スワイプ「戻る」と干渉しないため）。タッチ端末では HUD の ✥ ボタンで微調整パッド（移動・回転）を表示でき、連続した微調整は 1 手にまとまります。

## 収録
- **キャンペーン 8 章 43 ステージ**: 反射 / 分光 / 混色 / 屈折 / フィルタ / ガラス / 集大成 / 重力
- **エンドレス**: 解けることが保証された自動生成ステージ。クリアするたびに難度が上がる
- **デイリー**: 日付をシードにした今日のパズル（連続日数つき）
- **エディタ**: 自分でステージを作り、**共有リンク**（URL のハッシュに埋め込み）で配れる。解けている状態でのみ共有可能
- **ライトアート**: 生成した光の景色がゆっくり動き続ける鑑賞モード（クリックで次の景色）
- 画像保存（ポーズメニュー）、画質の切替、効果音・環境音の ON/OFF

## 構成
```
index.html / style.css   画面（タイトル・ステージ選択・HUD・クリア・エディタ）
js/optics.js    光学エンジン（DOM 非依存）。反射・屈折（分散・フレネル・全反射）・ハーフミラー・フィルタ・
                重力井戸での曲線光路。trace() が光線を追跡し、受光器の判定もここ
js/renderer.js  WebGL2 レンダラー。発光パス → ブルーム＋ストリーク → シーン（背景グリッド・SDF のガラス・塵）→ 合成（ACES）
js/shaders.js   GLSL（ビーム、ガラス/金属/ブラックホールなどの SDF シェーディング、ブルーム、合成）
js/game.js      状態・入力（ドラッグ/回転/タッチ）・当たり判定・ヒント・Undo・勝利演出
js/levels.js    キャンペーンのステージ定義（`route()` で折れ線からミラー配置を作る DSL、`tgtAuto` で受光器の条件を解から自動決定）
js/levels_master.js  生成器から選んで固定した「集大成」ステージ
js/gen.js       ステージ自動生成（解の配置を先に作り、そこへ届く光から受光器を決める。不要な部品は削る）
js/editor.js, js/share.js, js/modes.js  エディタ・共有リンク・エンドレス/デイリー
js/audio.js     WebAudio による効果音・環境音（ベル音、ペンタトニック、波長→音階）
js/fx.js        パーティクル
```

## 開発メモ
- ステージを足したら `python tools/prism/verify_levels.py`（Playwright + Chrome 必須）で全ステージを検証できます。
  「解で全受光器が点灯する」「開始状態で解けていない」「パーツが重ならない」「グリッド/角度がプレイヤーに再現できる」を確認します。
- `python tools/prism/level_sheet.py out.png 4-1 4-2 8-3` で解いた状態のスクリーンショットをまとめて出せます。
- 座標系は盤面 16×9、y が下向き、角度は x 軸から時計回り。可動パーツは「解の姿勢」を `x,y,a` に書き、開始時は自動でストック（盤面下部）に並びます。
- 受光器は `lo..hi`（波長帯）・`minE`（必要量）・`tol`（それ以外の色の許容量）で判定します。
- WebGL2 の浮動小数点レンダーターゲット（`EXT_color_buffer_float`）が必要です。MSAA は使わず、ブルームで光を表現しています。
- 画面が重いときは自動で解像度を下げます（ポーズメニューで固定も可能）。
