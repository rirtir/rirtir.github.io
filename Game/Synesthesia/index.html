あそびかた

  • 光のノーツが判定線に重なる瞬間に、そのレーンのキーを押します。
    DFJK（設定で変更可）／ スマホは画面下をタップ。
  • 長いノーツは押したまま。終端まで離さないと満点。
  • 自分の曲で遊べます。mp3 / wav / m4a / ogg をドラッグ＆ドロップ。音を解析してテンポ・ドラム・メロディの位置から譜面を自動生成します。ファイルは端末の外へ送られません。
  • 難易度は EASY〜EXPERT の4段階。どの曲でも選べます。
  • ハイウェイの両脇の街は、これから鳴る音のスペクトルです。街が立ち上がる方向を見れば、盛り上がりが先読みできます。
  • サバイバルは共鳴ゲージが0になると終了。オートは演奏を見るモード。
