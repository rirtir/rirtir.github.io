# SYNESTHESIA — 音が光になるリズムゲーム

**どんな曲も、光の回廊になる。** 手持ちの音楽ファイル（mp3 / wav / m4a / ogg …）をドラッグ＆ドロップすると、ブラウザ内で音を解析してテンポ・ドラム・メロディの位置から譜面を自動生成し、そのままプレイできるリズムゲーム。
ハイウェイの両脇に立ち並ぶ光の街は、**これから鳴る音のスペクトル**そのもの（解析結果を先読みして描画）です。

- 公開先: `https://rirtir.com/Game/Synesthesia/`（`Game/Synesthesia/index.html`）
- 技術: 素の HTML/CSS/JS（ES Modules）＋ WebGL2（HDR + ブルーム）＋ Web Audio。ビルド不要
- **音源ファイル・画像ファイルは一切なし**。収録の5曲もブラウザ内の自作シンセで楽譜から生成（フォントのみ Google Fonts）
- ユーザーの曲は端末の外へ送信されません（完全ローカル処理）

## 遊び方
| 操作 | 内容 |
|---|---|
| D F J K | 4レーンの打鍵（設定で変更可）。スマホは画面下部のレーンを直接タップ |
| 長押し | ホールドノーツ。終端まで押し続ける |
| Esc | ポーズ |
| ↑↓ ← → Enter | 曲選択画面での操作（曲 / 難易度 / 開始） |

- 難易度は EASY / NORMAL / HARD / EXPERT。どの曲でも選べる
- **サバイバル**: 共鳴ゲージが 0 になると終了。**オート**: 演奏を眺めるモード（記録なし）
- 判定は PERFECT ±50ms / GREAT ±100ms / GOOD ±150ms。スコアは 1,000,000 点満点の精度制
- リザルトでは、曲のスペクトルを円環に描いた **「音の肖像」** に打鍵（点）を重ねた画像を保存できる
- 設定: ノーツ速度、判定補正（メトロノームに合わせてタップする自動調整つき）、音量、ブルーム、カメラの動き、画質（自動で動的解像度）

## 構成
```
index.html / style.css   画面（タイトル・曲選択・HUD・リザルト・設定）
js/main.js       画面遷移・入力（キーボード/タッチ）・描画ループ・設定・リザルトの「音の肖像」
js/audio.js      Web Audio。出力遅延込みの曲時刻（getOutputTimestamp）→ 入力イベント時刻を曲時刻へ変換
js/game.js       判定・スコア・ホールド・オート。DOM 非依存
js/analyze.js    音声解析（STFT → 48バンド対数スペクトル / 4バンド群のオンセット / テンポ推定 / 拍追従 / ドロップ検出）
js/chart.js      譜面生成。候補ノーツ {t,pos,imp,dur} から難易度別にレーン配置（組み込み曲もユーザー曲も同じ処理）
js/synth.js      自前 DSP のシンセ・ドラム・FX・リバーブ・サイドチェイン・マスタリング（Float32Array に直接レンダリング）
js/songs.js      組み込み5曲の楽譜（音と同時に譜面候補も出力）
js/synth.worker.js  曲の生成を Worker で実行（失敗時は本スレッドで実行）
js/renderer.js, shaders.js  WebGL2。空(オーロラ/星/稜線) → 床への映り込み → 床 → ノーツ/柱/火花 → ブルーム → 合成
js/demo.js       曲未選択時の背景用デモ
```

## 仕組みのメモ
- **同期の取り方**: `AudioContext.getOutputTimestamp()` で「いま耳に届いている曲の秒」を求め、フレームごとに滑らかに補正。キー入力は `event.timeStamp` をその時刻系へ変換して判定するため、フレームレートに依存しない。
- **譜面生成**: オンセットを帯域群（キック/低中域/中域/高域）ごとに検出し、重要度 `imp`（拍との位置関係も加味）で間引く。レーンは「新しく現れた周波数の重心」の分位数で左右に散らし、連打・大きな跳躍・同時押し数を難易度ごとに制限。長く伸びる音はホールド候補になる。
- **組み込み曲**: 楽譜（コード進行・メロディ）から波形と譜面候補を同時に生成。高難易度は実音から検出したオンセットも足して密度を稼ぐ。
- **映像**: 地形の曲がり・カメラは曲の強度に追従。床はオーロラ空をその場で反射、柱は床にも映る（反転描画）。キックでカメラが膨らみ、ドロップで閃光。

## テスト
`python -m http.server` で配信し、`?song=neon-dawn&diff=2&auto=1`（曲 id / 難易度 0-3 / オート）で即プレイ。デバッグ用に `window.__syn`（`seek(t)` など）を公開している。
