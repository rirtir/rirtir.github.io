# 陽だまりクラフト — アートガイド

- 版: 1.0
- キーワード: `sun-washed / toy-like / botanical / clear / handmade pixels`
- 禁止語: `dark / grim / muddy / photoreal / noisy / low-contrast`

## 1. アートディレクション

島全体を「夏休みに机の上へ広げた、光る箱庭」として描く。16px単位の輪郭が明快なドット絵、少ない色数、1〜2pxの濃色アウトライン、右下へ落ちる短い影を共通文法にする。暗さで雰囲気を作らず、色相、彩度、密度、風の動きで時間と場所を表す。

### 1.1 守る原則

- 背景より操作対象を12%以上明るくするか、2段階濃い輪郭で囲む。
- 細部よりシルエット。100%表示でなく50%縮小でも対象を識別できること。
- 1スプライト内の主要色は原則6色以内、アウトラインとハイライトを含め最大10色。
- 完全な黒 `#000` は使わない。最暗色は青紫 `#27324D`。
- 真っ白はUIの重要文字だけ。自然物のハイライトはクリーム `#FFF4C7`。
- 危険色は珊瑚色、使用可能はミント、特別報酬は金色。色だけでなく形とアニメも変える。
- サブピクセル補間を使わず、CanvasとCSS画像は `image-rendering: pixelated`。

## 3. ピクセル規格

- タイル: 16×16px。画面上は整数倍率を優先する。
- プレイヤー: 16×24px、8方向。頭部8px、胴8px、脚6px、影12×5px。
- 小型敵: 16×16または20×20px。番人32×32px。
- 木: 32×48px、岩16〜24px、設備16〜32px。
- アイテムアイコン: 16×16px。UI表示は2〜3倍。
- アニメ: 待機2〜4f、歩行4f、道具3f、攻撃4f、被弾2f。原則8〜12fps。
- 影は半透明ではなく、青緑または青紫のディザ2色。夜も輪郭と影が融合しない。

## 4. キャラクター

### 4.1 主人公

- 性別を限定しない小柄な漂着者。麦わら色のフード、白い上着、コーラルのスカーフ、青緑の短靴。
- 俯瞰で頭が最大面積。スカーフの1px尾で向きを補強する。
- 道具は右手側へ大きく見せ、斧=扇、つるはし=山形、槍=直線、竿=曲線で判別する。
- 被弾は赤塗りでなく、白い輪郭フラッシュとコーラルの星形を使う。

### 4.2 敵

- 芽スライム: 黄緑の雫、頭頂に二葉。跳躍前に葉が横へ開く。
- トゲウリ: 橙の丸、紫の三角棘。発射方向へ棘が伸びる。
- 泡ガニ: 水色の横長、白い泡盾。側面にコーラルの弱点印。
- 石ころ獣: 灰青の四角い塊、金色の目。突進前に砂埃を後方へ吹く。
- 森の番人: 角のような枝を持つ木偶。敵対時も葉は明るく、腐敗色を使わない。
- 岩丘の番人: 風車を背負う丸石像。修復可能な歯車をミントの輪郭で示す。

敵の危険予告はコーラル色の床形状＋白い縁＋収縮アニメ。高コントラストでは斜線パターンを加える。

## 5. 地形と背景

### 5.1 草原

黄緑の基面、4タイルに1つ以下の短い葉、白・黄・コーラルの小花。歩ける地面の模様密度は低く保ち、採集できる繊維は3本束と光点で区別する。

### 5.2 林

基面はミント寄りの緑。樹冠は若草→葉→深葉の3段、左上にクリームのハイライト。幹と採集ポイントが隠れないよう樹冠下を半透過するのでなく、手前の葉を短く描く。

### 5.3 浜と水

砂はクリームと蜂蜜色。波線は2px幅の白、水は浅水→海の2段。アニメは4フレームで水平へずらし、画面全体を点滅させない。釣れる地点は3つの小さな輪で示す。

### 5.4 岩丘

灰青の基面にラベンダーの影。鉱床は銅の斑点、光晶はシアンと金の交互ハイライト。歩行不能崖は南面を3px濃くし、上面との境界を明確にする。

### 5.5 時間変化

- 朝: クリームの薄いオーバーレイ、長めの青紫影。
- 昼: 原色パレット、短い影。
- 夕: 橙と桃色を5〜10%加算。
- 夜: ラベンダーと青へ色相移動。オーバーレイの不透明度は最大22%。採集物と敵輪郭は明度を維持。
- 雨: 空色の2px線を疎に表示。全体を灰色にせず、水面と葉だけ彩度を上げる。

## 6. 建築物

- 素材を正直に見せる。木は蜂蜜色＋濃茶の接合部、石は灰青＋ラベンダー影、銅は橙＋クリーム反射。
- 使用できる設備は上面に1px金色ハイライト。処理中は小さな煙・歯車・泡などの固有アニメ。
- 収納、制作、睡眠、調理はシルエットだけで区別する。
- 配置ゴースト: 有効はミントの市松、無効は珊瑚の斜線、装飾は金色の点線。
- 灯台は32×64px相当の中心ランドマーク。段階ごとに足場、枠、レンズ、光線を加え、世界の進行を遠目でも示す。

## 7. UIデザイン

### 7.1 形

- パネルはクリーム色の紙カード、4〜8px角丸、2pxの青紫輪郭、右下へ2pxの硬い影。
- ボタンは黄、ミント、水色の機能色。押下で1px沈み、影が消える。
- 危険操作は白地＋コーラル輪郭。常時真っ赤な大面積を作らない。
- タブは布の見出し風。選択中は上辺に3pxの色帯とアイコン。

### 7.2 タイポグラフィ

- システムフォントを使い、本文は `system-ui, "Yu Gothic UI", sans-serif`。
- タイトルのみCSSの角張った影でドット感を作る。画像内へ文字を焼き込まない。
- 最小12px、主要操作14〜16px。数値はtabular-nums。
- 長文を避け、操作説明は最大2行。日本語を基本とする。

### 7.3 HUD

- 体力=ハート、満腹=果実、潤い=しずく、スタミナ=稲妻。バーは形状アイコンと数値を併記。
- 時刻は太陽/月の円盤が横へ動く小型時計。天候を右へ置く。
- ミニマップは紙の正方形。未踏は白い雲、目的は金の菱形、プレイヤーは濃紺の三角。
- ホットバーは8枠。選択枠は金色の上下動、クールダウンは青い時計回りマスク。
- 文脈操作は動詞を表示する: `拾う / 切る / 掘る / 話す`ではなく`調べる / 釣る / 開く`。

## 8. アイコン体系

- アイテムは左上光、右下影、濃紺1px輪郭。
- 素材カテゴリ: 自然物は丸、鉱物は角、加工品は四角、特別品は菱形のシルエット。
- UIアイコン: バッグ、槌、地図、手帳、歯車、保存、音、閉じる、戻る、検索。
- 状態: 新規は金の小星、制作可はミント点、材料不足は灰色、重要目標は金の菱形。
- 高コントラスト時は資源カテゴリごとに角の記号を追加する。

## 9. VFXと画面演出

- 採集: 対象色の四角粒子＋白い1px星。寿命0.35秒。
- 制作: 素材アイコンが中央へ寄り、金の輪になる。0.55秒。
- 発見: 画面上部へ紙帯、金色の左右線。背景を暗転しない。
- 被弾: 60ms白フラッシュ、100msヒットストップ上限。赤い全面フラッシュ禁止。
- 回避: ミントの残像2枚。
- 灯台完成: 朝焼けグラデーション、海へ伸びる3色の光、花弁粒子。点滅なし。
- 画面揺れは最大3px/120ms。動き軽減ではカメラ固定と輪郭パルスへ置換。

## 10. タイトルとキービジュアル

- 横長の島景観。中央に修復後の灯台、手前に主人公、周囲に森・浜・岩丘・畑を一枚で見せる。
- 視点はゲームと同じ高めの斜俯瞰。明るい昼、クリームの雲、水色の海、若草と金色。
- 左上または中央上にHTMLタイトルを置ける空を残す。画像内に文字、ロゴ、UI、透かしを入れない。
- 暗部は面積15%未満。敵は脅威でなく島の住人に見える距離と表情。

## 11. 音との同期

- 採集の白星と木琴、制作の金輪と上昇アルペジオ、危険予告と木のクリックを同期する。
- 昼BGMは明るい4/4、夜は同じ旋律を6/8風に薄く変奏し、世界の連続性を保つ。
- 番人戦でも低音を濁らせず、マリンバと手拍子で緊張を作る。

## 12. アセット完成基準

- キービジュアル、OG画像、タイル/スプライトアトラス、UIアイコン、音源がすべてローカルに存在する。
- 画像生成プロンプト、手続き生成スクリプト、出力一覧を台帳へ残す。
- 文字・透かし・第三者ロゴ・不自然な暗部・画風混入がない。
- 1x/2x/3x表示でドット境界が崩れない。
- 夜色オーバーレイ上でもプレイヤー、敵、資源、建築ゴーストの識別が保たれる。
