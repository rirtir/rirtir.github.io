# 陽だまりクラフト — アートガイド

- 版: 3.0（P9）
- キーワード: `sun-washed / toy-like / botanical / clear / handmade pixels`
- 禁止語: `dark / grim / muddy / photoreal / noisy / low-contrast`

## 1. アートディレクション

島全体を「夏休みに机の上へ広げた、光る箱庭」として描く。粒の見える明快なドット絵、濃紺アウトライン、足元へ落ちる短い影を共通文法にする。操作対象は低解像度へ描き直さず、生成した高精細ドット絵を独立透過画像として自然比率で縮小表示する。暗さだけで雰囲気を作らず、色相、彩度、密度、風の動きで時間と場所を表す。

### 1.1 守る原則

- 背景より操作対象を12%以上明るくするか、2段階濃い輪郭で囲む。
- 細部よりシルエット。100%表示でなく50%縮小でも対象を識別できること。
- 1スプライト内の主要色は原則6色以内、アウトラインとハイライトを含め最大10色。
- 完全な黒 `#000` は使わない。最暗色は青紫 `#27324D`。
- 真っ白はUIの重要文字だけ。自然物のハイライトはクリーム `#FFF4C7`。
- 危険色は珊瑚色、使用可能はミント、特別報酬は金色。色だけでなく形とアニメも変える。
- サブピクセル補間を使わず、CanvasとCSS画像は `image-rendering: pixelated`。

## 3. ピクセル規格

- 背景: 512×512の生成地表を128ワールドpx周期の連続パターンとして16pxタイルへクリップする。
- プレイヤー: 8方向×待機・歩行の独立16画像。アルファ境界の下辺中央を足元とし、可視部分を画面上高さ44px・幅上限31pxで描く。
- 小型敵・資源: 独立透過画像を自然比率のまま高さ23〜58pxで描く。番人は高さ66px。
- 建築: 独立透過画像を自然比率のまま占有面積に応じて高さ43〜98pxで描く。
- アイテムアイコン: 原本1セル256px相当。UIでは32〜64pxへ縮小し、斧・つるはし・槍をシルエットだけで区別する。
- アニメ: 主人公は方向ごとに待機・歩行2フレーム。VFXは8〜12fps相当。
- CanvasとCSSは補間を切り、縮小後もドット境界を維持する。

## 4. キャラクター

### 4.1 主人公

- 主人公は島の職人「ヒナ」。栗色の跳ね髪、金の星形髪留め、黄色いスカーフ、青緑のオーバーオール、クリームの肩掛け鞄、珊瑚色の靴を固定する。
- 俯瞰で頭と顔を十分な大きさにし、正面・斜めでは目を読めること。スカーフの尾で方向を補強する。
- `hero-sheet-v3.png` を分離元とし、`generated-v4/hero/` の16画像を直接描画する。数値グリッドによる実行時切り出しは禁止する。
- 被弾は赤塗りでなく、白い輪郭フラッシュとコーラルの星形を使う。

### 4.2 敵

- 芽スライム: 黄緑の雫、頭頂に二葉。跳躍前に葉が横へ開く。
- トゲウリ: 橙の丸、紫の三角棘。発射方向へ棘が伸びる。
- 泡ガニ: 水色の横長、白い泡盾。側面にコーラルの弱点印。
- 石ころ獣: 灰青の四角い塊、金色の目。突進前に砂埃を後方へ吹く。
- 森の番人: 角のような枝を持つ木偶。敵対時も葉は明るく、腐敗色を使わない。
- 岩丘の番人: 風車を背負う丸石像。修復可能な歯車をミントの輪郭で示す。

敵の危険予告はコーラル色の床形状＋白い縁＋収縮アニメ。高コントラストでは斜線パターンを加える。

## 5. 地形と背景

### 5.1 草原

黄緑の基面に、細かな葉のピクセル群と疎な白・黄の小花を連続させる。地表の葉は輪郭なし・低コントラスト、採集できる繊維は濃紺輪郭、まとまった葉束、対象楕円で区別する。

### 5.2 林

林床は苔緑、土、落葉、青緑の葉片を連続テクスチャにする。樹冠は若草→葉→深葉の3段、左上にクリームのハイライト。幹と採集ポイントが隠れないよう樹冠下を半透過するのでなく、手前の葉を短く描く。

### 5.3 浜と水

砂はクリームと蜂蜜色の細かな風紋。水はターコイズの連続テクスチャを浅水と海で色分けし、少数の水平光だけを時間で動かす。画面全体を点滅・上下移動させない。釣れる地点は3つの小さな輪で示す。

### 5.4 岩丘

灰青の基面にラベンダーの影。鉱床は銅の斑点、光晶はシアンと金の交互ハイライト。歩行不能崖は南面を3px濃くし、上面との境界を明確にする。

### 5.5 時間変化

- 朝: クリームの薄いオーバーレイ、長めの青紫影。
- 昼: 原色パレット、短い影。
- 夕: 橙と桃色を最大13%加算。
- 夜: 青紫オーバーレイを最大40%まで連続的に増やし、主人公周囲の暖色光を残す。採集物と敵輪郭は識別可能にする。
- 明暗量は時刻の太陽高度から毎フレーム連続計算し、朝・昼・夕・夜ラベルの切替を照明段差へ使わない。
- 雨: 空色の2px線を疎に表示。全体を灰色にせず、水面と葉だけ彩度を上げる。

## 6. 建築物

- 素材を正直に見せる。木は蜂蜜色＋濃茶の接合部、石は灰青＋ラベンダー影、銅は橙＋クリーム反射。
- 使用できる設備は上面に1px金色ハイライト。処理中は小さな煙・歯車・泡などの固有アニメ。
- 収納、制作、睡眠、調理はシルエットだけで区別する。
- 配置ゴースト: 有効はミントの市松、無効は珊瑚の斜線、装飾は金色の点線。
- 灯台は32×64px相当の中心ランドマーク。段階ごとに足場、枠、レンズ、光線を加え、世界の進行を遠目でも示す。

## 7. UIデザイン

### 7.1 形

- パネルはクリーム色の紙カード、4〜8px角丸、2pxの青紫輪郭、右下へ2pxの硬い影。
- ボタンは黄、ミント、水色の機能色。押下で1px沈み、影が消える。
- 危険操作は白地＋コーラル輪郭。常時真っ赤な大面積を作らない。
- タブは布の見出し風。選択中は上辺に3pxの色帯とアイコン。

### 7.2 タイポグラフィ

- システムフォントを使い、本文は `system-ui, "Yu Gothic UI", sans-serif`。
- タイトルのみCSSの角張った影でドット感を作る。画像内へ文字を焼き込まない。
- 最小12px、主要操作14〜16px。数値はtabular-nums。
- 長文を避け、操作説明は最大2行。日本語を基本とする。

### 7.3 HUD

- 体力=ハート、満腹=果実、潤い=しずく、スタミナ=稲妻。バーは形状アイコンと数値を併記。
- 時刻は太陽/月の円盤が横へ動く小型時計。天候を右へ置く。
- ミニマップは紙の正方形。未踏は白い雲、目的は金の菱形、プレイヤーは濃紺の三角。
- ホットバーは8枠。選択枠は金色の上下動、クールダウンは青い時計回りマスク。
- 文脈操作は一つの行動ボタンで、対象に応じて `拾う / 切る / 掘る / 攻撃 / 食べる / 釣る / 使う` と具体的な結果を表示する。

## 8. アイコン体系

- アイテムは左上光、右下影、濃紺1px輪郭。
- 素材カテゴリ: 自然物は丸、鉱物は角、加工品は四角、特別品は菱形のシルエット。
- UIアイコン: バッグ、槌、地図、手帳、歯車、保存、音、閉じる、戻る、検索。
- 状態: 新規は金の小星、制作可はミント点、材料不足は灰色、重要目標は金の菱形。
- 高コントラスト時は資源カテゴリごとに角の記号を追加する。

## 9. VFXと画面演出

- 採集: 対象色の四角粒子＋白い1px星。寿命0.35秒。
- 制作: 素材アイコンが中央へ寄り、金の輪になる。0.55秒。
- 発見: 画面端の小型フィードへ短く追加する。進行に必須の警告以外で中央を塞がない。
- 被弾: 60ms白フラッシュ、100msヒットストップ上限。赤い全面フラッシュ禁止。
- 回避: ミントの残像2枚。
- 灯台完成: 朝焼けグラデーション、海へ伸びる3色の光、花弁粒子。点滅なし。
- 画面揺れは最大3px/120ms。動き軽減ではカメラ固定と輪郭パルスへ置換。

## 10. タイトルとキービジュアル

- 横長の島景観。中央に修復後の灯台、手前に主人公、周囲に森・浜・岩丘・畑を一枚で見せる。
- 視点はゲームと同じ高めの斜俯瞰。明るい昼、クリームの雲、水色の海、若草と金色。
- 左上または中央上にHTMLタイトルを置ける空を残す。画像内に文字、ロゴ、UI、透かしを入れない。
- 暗部は面積15%未満。敵は脅威でなく島の住人に見える距離と表情。

## 11. 音との同期

- 採集の白星と木琴、制作の金輪と上昇アルペジオ、危険予告と木のクリックを同期する。
- 昼BGMは明るい4/4、夜は同じ旋律を6/8風に薄く変奏し、世界の連続性を保つ。
- 番人戦でも低音を濁らせず、マリンバと手拍子で緊張を作る。

## 12. アセット完成基準

- キービジュアル、OG画像、タイル/スプライトアトラス、UIアイコン、音源がすべてローカルに存在する。
- 画像生成プロンプト、手続き生成スクリプト、出力一覧を台帳へ残す。
- 文字・透かし・第三者ロゴ・不自然な暗部・画風混入がない。
- 1x/2x/3x表示でドット境界が崩れない。
- 夜色オーバーレイ上でもプレイヤー、敵、資源、建築ゴーストの識別が保たれる。

## 13. 主人公改訂 — ヒナ

旧主人公のフード、白い胴、珊瑚色の帯だけの構成は、人物性と方向認識が弱いため廃止する。正式デザインは `assets/character-concept-v2.png`、分離元は `assets/hero-sheet-v3.png`、実ゲーム画像は `assets/generated-v4/hero/` とする。

### 固定識別子

- 栗色 `#7A4934` の丸い髪塊と、頭頂で右へ跳ねる一房。
- 顔側に金色の星形髪留め。縮小後も形を残す。
- 首元の黄色 `#FFD166` の三角スカーフ。進行方向と反対へ尾を出す。
- 標準服は青緑 `#2CB9A8` のオーバーオール、象牙色の袖、クリームの斜め鞄紐。
- 珊瑚色 `#EF6A67` の靴。地面影と同化しない明度を保つ。
- 肌は暖かな褐色。正面・斜め・横では目と口を読める大きさにし、背面では顔を描かない。

### サイズとアニメーション

- ゲーム上は高さ44px、幅上限31px。8方向それぞれに待機・歩行を持つ16枚。
- 16枚は最大寸法の共通透明キャンバスへ収めたうえで、実行時に各画像のアルファ境界を切り出す。可視高44pxと境界下辺中央の足元を統一し、方向変更で頭・足・当たり座標を動かさない。
- 髪塊、スカーフ、胴色、鞄、靴の5段階シルエットが、輪郭だけでも人物として読めること。
- 生成画像の顔・髪留め・鞄紐を保ち、歩行は同方向2セルを切り替える。
- 外見だけが変わらない名目上の着替えはUIへ出さない。正式外見は一つに固定し、愛着と一貫性を優先する。

### ポートレート

- 初回案内は実ゲームと同じ `generated-v4/hero/hero-down-idle.png` を使う。
- 背景はクリーム、枠は青緑と金。暗い背景、武器、険しい表情を置かない。
- 大判デザインとゲーム用スプライトの色、髪、ピン、スカーフ、鞄、靴を一致させる。

## 14. P8モバイルUI規則

- 右側の大ボタンは一つの文脈行動に統合し、採取・攻撃・使用を対象と選択物から自動決定する。別の道具使用ボタンを並べない。
- 行動ボタンには生成した現物アイコンと日本語動詞を併記する。PCキー、色だけの説明、抽象記号だけの説明は禁止する。
- 390×844では移動パッド124px、行動88px、回避58pxを基準とし、タップ領域を見た目と一致させる。
- バッグ、クラフト、建築、手帳は親指が届く画面下へ置く。案内と休憩だけを画面上へ置く。
- ホットバー、下部メニュー、移動パッド、行動、回避を重ねない。safe-areaと左右反転を扱う。
- 初回説明は実画面上の対象をスポットライト、枠、矢印で一つずつ指し示す。文章ページだけを先に読ませない。
- 常設安全地帯、秒数札、色名によるボタン説明を置かない。開始安全性は敵の初期配置とガイド中停止で保証する。
- 長押しの文字選択、画像ドラッグ、タッチコールアウトを禁止する。

## 15. P9独立画像運用

- `*-v3.png` は分離元として保存し、実行時のUI、アイテム、資源、敵、建築は `generated-v4/` の独立透過PNGを正式素材とする。
- 分離はアルファ連結画素の重心を意図セルへ割り当て、他セル画素を透明化する。全出力で4px以上の透明余白を保証する。
- UIへ絵文字、丸・ひし形・トランプのスート、環境依存グリフを使わない。体力は心臓、満腹は食事、水分は水滴、スタミナは走る靴として形を分ける。
- 建築一覧、配置中、解体確認、手帳、図鑑では、フィールドと同じ現物画像を表示する。
- SVGを新規採用する場合は必ず対象サイズへラスタライズし、透明背景・通常背景・暗い背景で目視する。P8の主要操作アイコンは生成PNGのためSVGを使わない。
- 原本のクロマキー色を透過処理し、縁の色かぶりを除去する。原本と透過版の両方を保存する。

## 16. P9夜表現

- 朝、昼、夕、夜は連続関数で世界描画の色を変え、時刻文字を読まなくても判別できること。
- 夜は世界を十分暗くする一方、操作UIは暗くしない。主人公、資源、敵、建築の濃紺輪郭を残す。
- 段階CSSフィルターは使わず、Canvasオーバーレイだけを毎フレーム更新する。最終確認は昼と夜の実ブラウザ画像を並べて評価する。

## 17. P9固定・接地表現

- 植物、作物、建築は足元をワールド座標へ固定する。全体の上下往復は落下物・浮遊物だけに限定する。
- 生えた繊維の風表現は根元中心の±0.012rad回転まで。ベリー低木、結晶、作物は上下移動させない。
- 主人公と敵は同じ足元座標へ半透明楕円影を置き、対象選択、危険予告、近接距離もその座標を使う。
