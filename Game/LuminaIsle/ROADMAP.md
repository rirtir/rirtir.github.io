## 完成条件

- GitHub Pagesと `file://` で、ビルド・サーバー・外部通信なしに起動する。
- 生成した高精細ドット絵をゲーム内へ直接使い、主人公・斧・つるはし・槍・主要資源・敵・建築を見た目だけで区別できる。
- タッチ操作は移動、単一の文脈行動、回避を基本とし、頻用メニューを画面下へ置く。
- 初回ガイドは実画面の対象をスポットライトと矢印で示し、ガイド中は時間と敵を止める。
- 開始地点周辺へ敵を生成せず、カウントダウンや安全地帯表示を出さない。
- 通常の採取、食事、日替わり、空振り操作で画面中央を塞ぐ通知を出さない。
- 建築は位置選択、回転、明示確定、キャンセルが成立し、現物または一覧から対象を確認して解体できる。
- 夜は昼と明確に異なり、同時に地形・資源・敵・建築を判別できる。
- 3スロット、オートセーブ、バックアップ復元、JSON入出力を維持する。
- 18群の自動テスト、22群の統合テスト、5群の長時間テストを通過し、BLOCKER/HIGH/MEDIUM既知不具合を0にする。
