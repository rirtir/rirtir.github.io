## 1. 開発方針

この文書はゲーム内容と開発判断を同時に固定する。会話履歴へ依存せず、このフォルダだけでいつでも再開できる状態を保つ。

### 1.1 ユーザー方針

- 2Dドットグラフィックの俯瞰型サバイバルクラフトを完成品として制作する。
- 画面を暗くせず、高明度・高判読性・温かい色を基本とする。夜間も遊びやすさを優先する。
- GitHub Pagesで動く完全静的構成とし、サーバー、ログイン、外部API、CDNを必要としない。
- セーブ機能を必須とし、通常保存に加えて破損復旧と入出力を備える。
- 仕様、アートガイド、画像・音響素材、実装、検証、追加要素監査の順で進める。
- 開発途中で思いついた有効な提案はユーザーへ判断を返さず、設計柱と工数を監査して仕様へ吸収する。
- 区切りではなく、本書の完成条件をすべて満たした時点を完成とする。
- 進捗は `ROADMAP.md`、素材は `ASSET_MANIFEST.md`、品質は `QA_CHECKLIST.md` で追跡する。
- ストーリー文は実装中に場当たり的に増やさない。短い固定文と環境表現だけで完結させる。

### 1.2 技術方針

- 素のHTML/CSS/JavaScript。ビルド工程、npm、フレームワークを使わない。
- 2D Canvasを主描画にし、DOMはタイトル、メニュー、ダイアログ、アクセシブルな操作UIへ使う。
- ローカルファイルを直接開いた場合も主要機能が動くよう、ES Modulesではなく順序付きclassic scriptを使う。
- 画像、フォント、音響はすべて同梱する。第三者アセットや通信依存を持たない。
- 固定タイムステップ、決定的シード、空間グリッドで再現性と性能を確保する。
- タッチ、マウス、キーボード、ゲームパッドを同じアクション層へ集約する。

## 2. 製品定義

### 2.1 タイトル

`陽だまりクラフト — LUMINA ISLE`

### 2.2 ジャンル

俯瞰型2Dサバイバルクラフト / 小規模オープンワールド生活ゲーム。

### 2.3 一文説明

明るい島を歩き、採集・道具作り・建築・農耕・釣りを重ね、三つの自然プリズムで古い灯台を再点灯する、短く完結して長く遊べるサバイバルクラフト。

### 2.4 設計柱

1. **明るさは機能** — 地形、採集物、敵、危険予告、UIを明度差と輪郭で一目で分ける。
2. **拾った物が次の行動になる** — 主要素材は複数用途を持ち、採集から60秒以内に新しい制作へ届く。
3. **拠点が目に見えて育つ** — 建築、畑、収納、灯りが世界上に残り、利便性と風景の両方を変える。
4. **穏やかだが無意味ではない生存** — 空腹・渇き・体力は計画を生むが、即死や全ロストで時間を奪わない。
5. **小さく完結、続けて自由** — 2〜4時間で灯台再点灯に届き、達成後は島の生活を無期限に続けられる。

## 3. 対象環境

- 主対象: デスクトップChrome/Edge/Firefox、iOS Safari、Android Chromeの現行系。
- 基準画面: 1280×720。最小: 320×568 / 568×320。
- 30fpsを下限、一般的な端末で60fpsを目標。低負荷設定では描画粒子と水面装飾を半減する。
- オフラインキャッシュ用Service Workerは使わない。GitHub Pagesと直接ファイル起動の双方で壊れないことを優先する。
- 画面外へ重要UIを置かず、safe-area insetと200%文字サイズを考慮する。

## 4. 世界と物語

### 4.1 前提

主人公は小舟の嵐避けで「ルミナ島」へ上陸する。島の中央には光を失った古い灯台があり、三地域の自然プリズムが戻れば海路を照らせる。住民との会話や長いカットシーンはなく、島の石碑、灯台の状態、主人公の短い手帳だけで目的を伝える。

### 4.2 固定テキスト

- 開始: `潮風は穏やかだ。まずは枝と石を集めよう。`
- 灯台: `三つの光が戻れば、この島はまた海路を照らす。`
- 森の石碑: `育つ光は、刈り取る手より、植える手を選ぶ。`
- 潮の石碑: `満ちる光は、急ぐ手より、待つ手を選ぶ。`
- 岩の石碑: `眠る光は、砕く手より、整える手を選ぶ。`
- 完成: `灯りは帰る道だけでなく、ここで暮らす場所も照らした。`

### 4.3 結末

灯台を再点灯すると短い朝焼け演出とスタッフ表示を行う。セーブはそのまま継続し、灯台から毎朝「光のかけら」を受け取れる。エンディング後限定の装飾レシピ4種と島評価を解放する。

## 5. ワールド

### 5.1 構造

- 72×72タイル、1タイル16論理ピクセル。外周は浅瀬と海で閉じる。
- セーブスロットごとの32bitシードから決定的に生成する。
- 中央南寄りに上陸浜と壊れた灯台。初回資源を必ず近傍へ配置する。
- 地形: 草原、花野、木立、岩場、砂浜、浅瀬、水辺、畑土、道。
- 固定ランドマーク: 灯台、森の祠、潮だまり、石の庭、古い井戸、野営跡。
- 島は一画面に収めず、カメラ追従と地図で探索する。マップの未踏領域は薄い雲で覆う。

### 5.2 地域

| 地域 | 主素材 | 危険 | 固有行動 | プリズム条件 |
|---|---|---|---|---|
| 陽だまり草原 | 枝、繊維、ベリー | 芽スライム | 採集・畑 | 導入地域 |
| こもれび林 | 木材、樹脂、種 | トゲウリ | 伐採・植林 | 木を3本植え、森の番人を鎮める |
| きらめき浜 | 貝殻、魚、潮結晶 | 泡ガニ | 釣り・潮位 | 異なる魚3種を潮の祭壇へ納める |
| ひかり岩丘 | 石、銅鉱、光晶 | 石ころ獣 | 採掘・精錬 | 三つの風車石を正しい向きへ直す |

### 5.3 時間と天候

- 1日12分。朝3分、昼5分、夕2分、夜2分。
- 夜の最低背景明度は約38%。地形は青紫、輪郭と採集物は金色・シアンで維持する。
- 晴れ70%、小雨20%、光雨10%。天候は1日単位で決定する。
- 小雨は作物へ水やりし、魚の出現率を上げる。移動や体温へ罰を与えない。
- 夜は敵が少し増えるが、希少素材と光る虫も増える。

## 6. プレイヤーと生存

### 6.1 基本値

- 体力100、満腹100、潤い100、スタミナ100。
- 満腹・潤いはゲーム内24時間で100から約25まで低下。0では体力が緩やかに減る。
- スタミナは走行、道具、回避で消費し、停止または歩行で即時回復する。
- ダメージ後1秒無敵。体力0で最後に寝た場所へ朝に戻る。
- 気絶時は所持品を失わず、その日の未保存位置と満腹・潤いだけを回復値へ戻す。

### 6.2 操作

- 移動: WASD / 矢印 / 左仮想スティック / ゲームパッド左スティック。
- 注目・使用: マウス左 / E・Space / 右主ボタン / Gamepad A。
- 道具: マウス左長押しまたはJ / 右主ボタン。向きは直前移動またはポインター位置。
- 回避: Shift / K / 補助ボタン / Gamepad B。
- ホットバー: 1〜8、ホイール、画面タップ、肩ボタン。
- インベントリ: Tab/I / バッグボタン / Gamepad Y。
- 地図: M / 地図ボタン / Gamepad Select。
- 一時停止: Esc/P / ポーズボタン / Gamepad Start。
- タップ移動は設定で有効化可能。誤操作防止のため既定は仮想スティック。

### 6.3 フィードバック

- 対象輪郭、行動名、必要道具を頭上に表示する。
- 行動成功時は素材アイコン、数値、短い音、6〜12個の粒子を出す。
- 使用不能時は理由を1行で表示し、同じ警告を連続再生しない。

## 7. 資源、道具、アイテム

### 7.1 資源

`枝 / 木材 / 石 / 繊維 / ベリー / 種 / 樹脂 / 貝殻 / 生魚 / 焼き魚 / 淡水 / 銅鉱 / 銅塊 / 光晶 / 光のかけら / 森・潮・岩のプリズム`

### 7.2 道具

- 石斧 → 銅斧: 木と樹脂。銅は範囲と速度を強化。
- 石つるはし → 銅つるはし: 石、鉱石、光晶。
- 木槍 → 光槍: 戦闘。突きと三段目ノックバック。
- 釣り竿: 水辺のタイミングゲーム。
- じょうろ: 井戸で補充し、畑4マスへ散水。銅版は9マス。
- 木槌: 建築物の配置・移動・解体。解体は素材100%返却。

道具は壊れない。クラフトの喜びを保ち、反復修理の負担を排除する。

### 7.3 食料

- ベリー: 満腹+10、潤い+4。
- 焼きベリー: 満腹+18。
- 焼き魚: 満腹+36、体力+10。
- サンルートスープ: 満腹+55、潤い+20、スタミナ最大+20を2分。
- きらめき串: 満腹+42、体力+25、発光を2分。

## 8. クラフト、建築、農耕

### 8.1 制作台

- 手作り: 石斧、石つるはし、木槍、たいまつ、焚き火、簡易寝袋。
- 作業台: 釣り竿、木槌、じょうろ、木箱、柵、床、橋、看板、家具。
- 炉: 銅塊、銅道具、灯台レンズ枠。
- 調理鍋: 上位料理。

### 8.2 建築

- 1タイルグリッド。配置可能は緑、衝突は赤、装飾は黄のゴーストで示す。
- 建築物: 焚き火、作業台、炉、木箱、寝袋、ベッド、畑、井戸ポンプ、木床、石床、柵、門、橋、ランタン、旗、鉢植え、ベンチ、灯台部品。
- 木槌で再配置・90度回転・解体。収納中の木箱は解体不可。
- 通行経路を完全封鎖する配置は許可するが、メニューの「安全地点へ戻る」で脱出可能。

### 8.3 農耕

- 畑を置き、種を植え、水を与える。3回の朝更新で収穫。
- 雨は全作物へ給水。近くのランタンで1段階だけ育成を短縮する。
- サンルート、ベリー低木、光花。収穫時に種を必ず1個返す。

### 8.4 レシピ解放

- 素材を初取得した時点で関連レシピを自動発見する。
- 灯台・祭壇・作業台レベルで高度レシピを解放する。
- レシピ帳は「今作れる」「新規」「設備別」で絞り込める。

## 9. 探索、戦闘、釣り

### 9.1 敵

1. 芽スライム — 直線跳躍。攻撃前に葉が開く。
2. トゲウリ — 三方向に種を飛ばす。橙色の予告線。
3. 泡ガニ — 正面防御、横から攻撃すると気絶。
4. 石ころ獣 — 遅い突進。壁へ当てると鉱石を落とす。
5. 森の番人 — 小ボス。切った木を植え直す行動で弱体化。
6. 岩丘の番人 — 小ボス。三つの風車石を直すと戦闘なしでも解決可能。

- 敵はプレイヤーから一定距離を超えると帰還し、拠点内部へ侵入しない。
- 撃破で消滅ではなく光粒へ戻り、翌朝に再出現する。
- ボスは戦闘または地域の課題解決で鎮まり、殺生を強制しない。

### 9.2 戦闘

- 武器の向きは8方向。通常三連、長押し溜め、回避後の一撃。
- 当たり判定は円と扇形。敵予告は最低0.65秒、ボスは1.0秒。
- 攻撃・被弾・回避に短いヒットストップを入れるが、動き軽減では無効化する。
- 敵HPバーは交戦中のみ表示。色だけに頼らず形状と点滅で危険を示す。

### 9.3 釣り

- 水辺で竿を使用し、浮きが沈んだ1.2秒以内に合わせる。
- その後、左右へ動く魚マーカーを安全帯へ合計3秒保つ。
- 失敗しても餌や耐久を失わない。時間帯、天候、場所で魚6種を分ける。

## 10. 進行と目標

### 10.1 導入手帳

1. 枝3・石3を集める。
2. 石斧を作る。
3. 木を切り、焚き火を置く。
4. 食べ物を焼き、夜を越す。
5. 作業台を作る。
6. 灯台を調べ、三地域のプリズム目標を解放する。

### 10.2 灯台段階

- 0 破損: 地図と三祭壇を発見可能。
- 1 台座修理: 木材20、石20。地図に地域輪郭を表示。
- 2 レンズ枠: 銅塊8、光晶5。夜の最低明度をさらに上げる。
- 3 三プリズム: 各地域課題。最終起動が可能。
- 4 再点灯: エンディング、毎朝報酬、装飾、島評価を解放。

### 10.3 島評価

自然、生活、発見の3軸各0〜5。植林、畑、装飾、料理、魚図鑑、地図踏破で上昇し、15で金色の灯台外観を解放する。数値上のエンドコンテンツであり、減少しない。

## 12. セーブ仕様

- 3スロット。主キー `luminaIsle_save_v1_slot_N`、バックアップ `_backup`、一時 `_tmp`。
- 保存前に現在の主データをバックアップへ移し、一時キーへ書き込み、JSON再解析とチェックサム確認後に主キーへ確定する。
- 30秒オートセーブ、就寝、建築、重要進行、`visibilitychange`、ポーズ終了で保存する。
- 保存対象: schemaVersion、seed、乱数状態、日時、天候、プレイヤー、所持品、ホットバー、設備、収納、作物、地形変更、資源の再出現日、地域進行、灯台、地図、実績、統計、設定。
- 敵と粒子は保存せず、安全なスポーン規則で再生成する。
- 起動時は主→バックアップの順に検証し、復元時は通知する。両方不正なら上書きせず、削除かJSON読込を選べる。
- スロットごとのJSONファイル書き出し・貼り付け/ファイル読込・二段階削除を持つ。
- スキーマ移行関数を用意し、未知の将来版は読み込まず明示する。

## 15. 性能と安全策

- 描画は可視タイルのみ。エンティティは空間グリッドで近傍検索する。
- 最大: 資源350、建築400、敵24、粒子250。上限超過時は古い装飾粒子から削除する。
- `devicePixelRatio` は最大2、低負荷1。Canvas内部解像度を表示サイズに追従する。
- 長時間停止時のdeltaを100msに制限し、復帰時のワープと生存値急減を防ぐ。
- 入力中に画面回転・タブ非表示となった場合は移動・攻撃・建築を解除し自動停止する。
- ローカルストレージ不足時はゲームを継続し、保存失敗と書き出しを案内する。

### 初回導線と開始安全性

- 新規開始時は時間と敵AIを停止し、実画面上の主人公、移動、行動、ホットバー、下部メニュー、目標を一つずつ強調する。

### スマホ操作

- 左側を移動パッド、右側を単一の文脈行動と回避にする。道具使用と調査を別ボタンへ分けない。
- 文脈行動は対象と選択中アイテムから、拾う、切る、掘る、攻撃、食べる、飲む、釣る、植える、収穫、使うを決める。
- 対象がない場合は無反応を基本とし、「近くに調べられるものはない」等の通知を出さない。
- ホットバーは現物アイコン、行動ボタンは現在の動詞と選択物アイコンを表示する。タッチ画面へPCキーを出さない。
- バッグ、クラフト、建築、手帳は画面下部へ、案内と休憩だけを上部へ置く。
- 利き手反転、ボタン倍率、safe-area、pointercancel、画面回転、長押し選択防止を扱う。

### 建築

- 建築一覧には建築物の現物画像、名称、用途、材料を表示する。

- 回転は表示画像と占有幅の両方へ反映する。配置可能はミント、不可は珊瑚の枠と面で区別する。
- ハンマー選択中はフィールド上の建築物を直接指定して解体できる。
- 一覧からの管理は対象位置へカメラを動かし、対象名と現物画像を出した確認を経て解体する。

- 採取、食事、飲水、日付変更、回転、通常配置は画面端の小型フィードまたは無通知とし、中央を塞がない。

- 同一警告を重ねず、画面上に残る通知数を制限する。
- 夜は昼より明度と彩度を下げ、青紫へ色相移動する。世界だけを変化させ、操作UIと文字の可読性は維持する。
