# 陽だまりクラフト — LUMINA ISLE

明るいルミナ島を舞台にした、俯瞰型2Dドット絵サバイバルクラフト。採集、クラフト、建築、農耕、料理、釣り、戦闘を重ね、森・潮・岩のプリズムで古い灯台を再点灯する。

## 起動

`index.html` を直接開くか、このフォルダを静的HTTPサーバーで配信する。ビルド、インストール、サーバー処理、外部通信は不要。

公開URL: `https://rirtir.com/Game/LuminaIsle/`

## 主な内容

- シードで決まる72×72タイルの島と、草原・林・浜・岩丘の4地域
- 体力、満腹、潤い、スタミナを使う穏やかなサバイバル
- 固有主人公「ヒナ」、8方向4フレーム、解放式の仕事着5種
- 壊れない道具と最高級道具5種、25レシピ、27種の建築、料理と精錬
- 作物3種、範囲水やり、スプリンクラー、温室、雨による自動給水
- タイミング式の釣りと、条件の異なる魚図鑑10種
- 通常敵4種、番人2種、予告表示、回避、平和的な地域解決
- 三つの地域課題、灯台4段階、エンディング、クリア後装飾4種
- 日替わり依頼3件、6系統×10段階の熟練度、記章で覚える技能12種
- 島の記憶8個、手帳、地図、30点満点の島評価、実績33件
- 初回3ページ案内、常設安全地帯、開始後120秒の準備時間
- マウス/キーボード、タッチ、ゲームパッド対応
- 高コントラスト、動き軽減、UI倍率、低負荷、生存/戦闘補助

## 操作

| 行動 | キーボード / マウス | タッチ | ゲームパッド |
|---|---|---|---|
| 移動 | WASD / 矢印 | 左スティック | 左スティック |
| 近くの対象へ行動 | E / Space / 左クリック | 黄色の文脈ボタン | A |
| 選択アイテムを使う | 1〜8で選択後に行動 | 緑のアイテムボタン | A |
| 回避 | Shift / K / 右クリック | 「回避」 | B |
| ホットバー | 1〜8 / ホイール | 枠をタップ | LB / RB |
| バッグ | I / Tab | バッグ | Y |
| クラフト | C | 作る | メニュー |
| 建築 | B | 建てる | メニュー |
| 地図 | M | ミニマップ | メニュー |
| 休憩 | Esc / P | 休憩 | Start |

スマホでは採取・調査用の黄色ボタン、選択アイテム用の緑ボタン、回避用の白ボタンを分離している。ボタン名は「拾う」「切る」「食べる」「攻撃」など現在の結果へ変化する。操作説明は右上の「？」または開始地点の案内板から何度でも開ける。

## セーブ

- localStorageへ3スロット保存
- 30秒ごとの自動保存、就寝、建築、重要進行、タブ非表示時の保存
- 主データ、バックアップ、一時検証の三段階書き込み
- チェックサム検証とバックアップからの自動復元
- JSONファイル書き出し、貼り付け/ファイル読込、二段階削除
- スキーマバージョン付き。未知の将来版は上書きせず拒否する

ブラウザのサイトデータを消すとローカルセーブも消える。長期保存にはセーブ管理からJSONを書き出す。

## 開発・再開

- `SPEC.md` — ゲーム内容と開発方針、完成条件
- `ART_GUIDE.md` — 世界観、色彩、UI、キャラクター、背景、演出
- `ROADMAP.md` — 現在地と次の一手
- `ASSET_MANIFEST.md` — 画像・音響台帳
- `QA_CHECKLIST.md` — 対象環境とリリース基準
- `tools/generate_assets.py` — 273スプライトの決定的アトラス生成
- `tools/generate_audio.py` — BGM4曲・効果音15種のオリジナル合成

ブラウザ内テストは `index.html?selftest=1`、主要機能の統合テストは `index.html?integration=1`、30分相当更新は `index.html?longrun=1` で実行できる。テスト用クエリは通常プレイのUIには現れない。

## 素材と権利

外部ライブラリ、外部フォント、第三者画像、第三者音源は使用していない。

- タイトル画像と主人公デザインシート: OpenAI built-in imagegenで本作専用に生成。最終プロンプトは `assets/IMAGE_PROMPT.md`。
- ゲーム内ドット絵: `tools/generate_assets.py` と `ART_GUIDE.md` に基づく本作専用生成物。
- 音楽・効果音: `tools/generate_audio.py` による本作専用の波形合成・作曲。
- UI: HTML/CSSと本作専用SVG。

生成原本を含む全ファイルを同梱しており、実行時に素材提供元へ通信しない。
