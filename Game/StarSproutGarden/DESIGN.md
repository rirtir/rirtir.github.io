# 星の芽の庭 / STARSPROUT GARDEN 設計書

## 1. 概要と分担
夜の温室で光る星の植物を育てる放置ゲーム。初回は約15分で「星の花」に届く。
- **Opus**：設計（本書）
- **Sonnet**：`index.html` / `style.css` / `game.js` の実装
- **Codex**：`assets/stage-0〜4.svg`（透明背景、320×360、種→芽→若葉→つぼみ→星の花）と `assets/garden-bg.svg` の作成、テスト

## 2. 画面
- 配色：背景 #0d1530、ミント #7fe0c4、金 #e8c46a。共通CSS `../../css/common-style.css` を読み込む。
- PC（幅900px以上）：3列グリッド。左が育成（しずく数、毎秒量、成長バー、収集ボタン）、中央が植物、右が設備。
- スマホ：縦並び。植物、収集ボタン、育成、設備の順。下部に「実績」「遊び方」「設定」のタブを置く。

## 3. 数式
- 1タップの獲得量：`(1 + じょうろLv) × M`
- 毎秒の獲得量：`(0.5 + 1.0 × ランプLv) × M`
- 全体倍率：`M = (1 + 0.25 × 鉢Lv) × (1 + 0.1 × 星)`

| 設備 | 価格（n＝現在Lv） |
|---|---|
| 露のじょうろ | `floor(10 × 1.45^n)` |
| 月光ランプ | `floor(25 × 1.40^n)` |
| 星砂の鉢 | `floor(300 × 2.0^n)` |

- 成長段階（累積獲得量で判定）：0 / 30 / 300 / 1500 / 6000
  - 試算：ランプ約10Lv（累計約1700）で毎秒10前後、鉢2Lvで約×1.5。平均毎秒7程度で約15分になる。
- 星の収穫：最終段階で「星を収穫」ボタンを押す。獲得数は `1 + floor(log2(累積 / 6000))`。
  - しずく、設備、累積はリセットし、星と実績は残す。

## 4. 実績（8種）
初しずく、100タップ、ランプLv5、鉢を購入、つぼみ到達、初めての星、星5個、オフライン帰還。

## 5. 保存と時間
- キー `starsprout.v1` に `{ver, drops, total, lv:{w,l,p}, stars, ach[], tapCount, lastSeen}` を保存する。
- 保存のタイミング：5秒ごと、`visibilitychange`、`pagehide`。
- **壊れた保存データ**：JSONの解析失敗、または数値が有限で0以上でない場合は初期値で始める。元の文字列は `starsprout.v1.bak` に退避し、その旨を通知する。
- **オフライン進行**：`経過 = clamp(now − lastSeen, 0, 8h)` として、`経過秒 × 毎秒量 × 0.5` を付与し、帰還ダイアログで表示する。
- **異常な時刻差**：経過がマイナスなら0として扱い、lastSeenを現在時刻に更新する。ゲームループの差分は最大1秒に制限し、それ以上の空白はオフライン処理に回す。
- **複数タブ**：起動時にtabIdを生成する。`storage` イベントで別タブの保存を検知したら、そのタブは保存を停止し「他のタブで開かれています（再読み込みで続行）」と表示する。

## 6. アクセシビリティ
- 成長バーは `role="progressbar"` と `aria-valuenow` を持たせる。
- 段階変化と実績解除は `aria-live="polite"` で読み上げる。しずく数の読み上げは10秒に1回までに抑える。
- 植物画像のaltには段階名を入れる。設備ボタンのaria-labelは「月光ランプ Lv3、価格120」の形式にする。
- 初期化には `<dialog>` を使う。フォーカスを閉じ込め、Escでキャンセルできるようにする。
- `prefers-reduced-motion` と設定画面のトグルで、揺れ・粒子・発光の明滅を停止する。

## 7. 遊び方（画面に表示）
「しずくを集めて設備を育て、星の花を咲かせよう。収穫した星は次の庭を永く照らします。」

## 受け入れ条件
1. ビルドなしで `Game/StarSproutGarden/index.html` が動作し、外部通信が発生しない。
2. 初期状態から操作と購入を続けると、15分前後で第5段階に到達する。
3. 再読み込み後も状態が復元され、閉じていた時間（上限8時間）の50%分が付与される。
4. 壊れたJSONや負の時刻差でもエラーで止まらず、初期化またはスキップされる。
5. 星を収穫するとリセットされ、星による倍率が次の周回に反映される。
6. キーボードだけで全操作ができ、reduced-motion時はアニメーションが停止する。
