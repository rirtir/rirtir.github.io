# ケモノキャラクリ（Game/KemonoCreator）

ブラウザで動く、アニメ調3Dのケモノ（獣人）男性キャラクタークリエイトです。ゲーム部分はなく、キャラクターを作って眺める・撮影する・コードで保存することに特化しています。

公開URL: https://rirtir.com/Game/KemonoCreator/

## できること

- **種族プリセット 12種**（狼・柴犬・狐・猫・虎・獅子・熊・兎・黒豹・ハスキー・ドーベルマン・ハイエナ）と、すべて／色だけのランダム生成
- **体型**: 身長・筋肉・肉づき・お腹・肩幅・胸板・胸筋・ウエスト・胴/首/腕/脚の長さと太さ・手足の大きさ・腰幅・お尻・ふくらはぎ
- **頭・顔**: 頭の大きさ/幅/頭頂の高さ・おでこ・眉骨・頬・あご・額とマズルの段差
- **マズル**: 長さ・太さ・厚み・先端の細さ・角度・鼻筋の高さ・上唇のふくらみ・下あごの長さ
- **目**: 大きさ・縦の幅・つり目/たれ目・まぶたの丸み・位置・瞳の大きさ/色（上下2色）・瞳孔の形（丸/縦長/なし/横長）・ハイライト・まぶたの線・まつげ・眉（線/麻呂眉/太眉）
- **鼻・口**: 鼻の形（犬/猫/熊/ハート/丸）・大きさ・色・つや、口の高さ/長さ・口角・ω口・鼻下の線・牙、ヒゲ（本数・長さ・たれ具合・色）
- **耳**: とがり耳/大きいとがり耳/猫耳/丸耳/垂れ耳/うさぎ耳、大きさ・幅・長さ・丸み・くぼみ・先の垂れ・位置・角度・耳の中の毛・耳先の色
- **髪・たてがみ**: 髪型7種（長さ・ボリューム・鋭さ・ランダムさ・流れ・毛先の色）、頬毛（小/大/二段）、たてがみ、あごの毛
- **体毛**: 胸毛・首まわり・肩・背中・ひじ・手首・かかとの毛の房、輪郭の毛のふさふさ、影の毛並み表現
- **尻尾**: 狼/狐/猫/獅子/熊/うさぎ、長さ・太さ・ふさふさ・上げ具合・巻き・先の色・揺れ
- **毛色・模様**: メイン/サブ/手足の先/肉球の色、腹・マズル・頬の塗り分け、縞/斑点/ぶち、背中・目のまわり・額の模様、境目のギザギザ
- **服**: タンクトップ/Tシャツ/長袖、ショート/ハーフ/ロングパンツ、ベルト・スカーフ・腕輪
- **ポーズ・表情**: 自然体/Aポーズ/腰に手/手を挙げる、ふつう/笑顔/にっこり/怒り/驚き/ジト目/目閉じ、口の開き、まばたき・待機モーション・カメラ目線
- **表示**: 明るいスタジオ／星空ステージの背景、顔の3面プレビュー（BLUE PROTOCOL のキャラクリ画面を参考）、輪郭線の太さ・アニメ度・影の色味・リムライト・ライトの向き
- 元に戻す/やり直す（Ctrl+Z / Ctrl+Y）、キャラコードでの保存・共有、PNG撮影、自動保存（localStorage）

## しくみ

### 体のメッシュ（`tools/`、Python + Blender）

1. `kemono_sdf.py` … 体を楕円体・ラウンドコーンのスムーズ和（SDF）で定義。パラメータ（-1〜1）から形と関節位置を作る。
2. `mesh_sdf.py` … 4.5mm グリッドで SDF を評価してマーチングキューブで高解像度メッシュ化（約28万三角形）。
3. `blender_decimate.py` … Blender 3.2 をバックグラウンドで起動し、左右対称を保って約4.4万三角形へ間引く。
4. `build_body.py` … 各スライダーの両端のパラメータで SDF を作り直し、プリミティブごとの対応で頂点を移してから新しい表面へ投影 → **モーフターゲット 68個**として書き出す。スキンウェイト（プリミティブの所属から計算）、マスク（マズル/頭/肉球/腕・脚の位置）、トゥーン用のなだらかな法線（表面から少し離れた点の SDF 勾配）も作る。
5. 出力は `assets/body.bin`（約4MB）と `assets/body.json`。

まとめて実行: `sh tools/build_all.sh 0.0045 44000`（10分ほど）。形の確認は `blender_preview.py` で Workbench レンダリング。

### 描画（`js/`、three.js r186）

- `toon.js` … MeshToonMaterial を差し替えたアニメ調シェーダー。2段ランプ＋色付きの影、リムライト、画面幅一定の反転ハル輪郭。**目・眉・口・毛色の塗り分け・模様はシェーダー内で描く**ので、マズルや頭の形を変えても表面に追従する。
- `body.js` … モーフと骨の管理。体型を変えるたびに骨の休止位置をモーフ後の関節へ合わせ、逆行列を作り直す。
- `parts.js` … 耳・毛の房・尻尾・鼻を手続き生成。`character.js` が体の表面（モーフ後）を探してボーンに取り付ける。
- `character.js` … 服（体を法線方向にふくらませた殻をシェーダーで切り抜く）、ポーズ・表情・まばたき・待機モーション。
- `ui.js` / `schema.js` … 項目定義から UI を自動生成。
