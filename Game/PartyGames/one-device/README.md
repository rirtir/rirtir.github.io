# 1台で遊ぶミニゲーム集

スマートフォン1台を順番に受け渡して遊ぶ、サーバー不要の16ゲームです。
`games/` 以下にゲームごとの独立フォルダがあり、回答とスコアはブラウザ内だけで
保持します。秘密のお題・回答・投票の前後には必ず受け渡し画面を表示します。

お題データはオンライン版と同じデータセットです。参照元・再配布条件は
`licenses/SOURCES.md`、`licenses/`、および各数値問題の `source` / `source_url` を参照してください。

GitHub Pagesでは `/Game/PartyGames/one-device/` から起動します。
